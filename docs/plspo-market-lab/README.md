## 원문과 계산의 경계

엑박 원문 촬영158/R8 p163은 `α×β×γ=SPX`, 161/p166은 성장(Quality), 유동성(Quantity), 심리(Sentiment)를 설명한다. 여기의 α는 초과수익률, β는 CAPM 베타가 아니다. 단위·계수·기준점이 없어 지수 수준을 특정하지 못하며 두 항을 음수로 놓으면 곱은 양수가 된다. “어느 하나가 음수면 하락” 및 “크기와 상쇄”라는 설명을 동시에 문자 그대로 예측 법칙으로 사용하지 않는다.

새 연구 후보는 현재값을 제외한 과거 창의 중앙값/MAD로 각 대리지표를 표준화한다:

`zᵢ = clip(directionᵢ × (xᵢ − median(historyᵢ)) / (1.4826 × MAD(historyᵢ)), −3, 3)`

`S = (zα + zβ + zγ) / 3`

일정한 과거값으로 MAD가0, 표본 부족, 관측 시차 초과, 원천 수집 실패 중 하나라도 있으면 종합 S는 null이다. 결측을0으로 채우거나 남은 축의 비중을 다시 키우지 않는다. 동일 비중·보정창·±3 제한·±0.5 표시는 학습되지 않은 서비스 가정이다. 지표 간 상관·중복 측정·정책의 내생성·GDP의 공표/수정 시차 때문에 S를 인과 효과·상승 확률·주가 예측으로 해석할 수 없다.

조건 실험은 실제 관측과 완전히 분리한다. 비음수 가중치를 합1로 바꾸고 `cᵢ=wᵢzᵢ`, `Aᵢ=exp(λcᵢ)`, `I=100∏Aᵢ=100exp(λS)`를 표시한다. I는 무차원 기준100의 가상 지수이지 실제 SPX나 기대수익이 아니다. λ=0.1은 임의 민감도다. 두 음의 충격을 양의 증시 예측으로 뒤집지 않는다는 대수적 성질만 검사했다. 예측력이 입증된 것은 아니다.
