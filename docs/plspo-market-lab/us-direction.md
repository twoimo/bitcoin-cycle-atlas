# 미국 시장 UP/DOWN과 공식 자료 자동 확인

2026-11-03 사용자 요청에 따라 `/market-lab/us/`의 중앙 화면에 S&P 500 모형 방향을 연결했다. 기존 상하좌우 패널, 관측 차트·선택 종목/날짜·국내 진단·RSI·조건 실험과 계산은 유지한다.

## 식과 해석

기존 원문 기록은 촬영158/R8 p163의 `α×β×γ=SPX`, 촬영161/p166의 성장·유동성·심리다. 현재 Plaud 메모 287개 중 관련 항목124/126/127/130/143도 확인했다. 이들은 촬영 설명/메모이며 원음 직접 청취·전사나 원문의 정량 계수 검증이 아니다. 다수 항목의 시각이 동일하여 정확한 발언 시각으로 쓰지 않는다. 전체 개인 메모·촬영 이미지·녹음은 제품에 복사하지 않는다.

앱의 `proxy-product-1`은 기존 각 축의 중앙값/MAD 표준화 값 `zα,zβ,zγ`를 사용한다. 과거 창에서 최신값을 제외하는 계산·방향·±3 제한은 바꾸지 않았다. 곱 `P=zα×zβ×zγ`가 양수면 UP, 음수면 DOWN이다. 0이거나 세 축 중 하나가 결측·노후·원천 오류·미래 관측이면 판정을 유보한다. 두 음수의 곱은 양수이므로 이 규칙은 ‘한 축이라도 음수면 DOWN’과 다르다.

GDP·국채금리·VIX는 강연 개념의 일부 대리값이다. 원문의 EPS·유동성 총량·AAII/CNN과 같지 않으며 원식의 단위·계수·기준점·예측 기간은 확인되지 않았다. UP/DOWN은 이 대리지표 곱의 방향이며 실제 S&P 500의 미래 등락·확률·매매 수익을 확정하지 않는다. 기존 평균 `(zα+zβ+zγ)/3`은 별도 접기 영역과 기존 API diagnostics에 보존한다. 평균과 곱의 부호가 항상 같다고 가정하지 않는다.

## 수집 원천과 주기

| 축 | 공식 배포 원천 | 발표 주기 | 적용 |
|---|---|---|---|
| α 성장 | [FRED / BEA GDPC1](https://fred.stlouisfed.org/series/GDPC1) | 분기 | SAAR 수준비의 전기비 `100×(당기/전기−1)`, 연율 성장률 역변환 아님 |
| β 유동성 | [FRED / 연준 H.15 TB3MS](https://fred.stlouisfed.org/series/TB3MS) | 월간 | 3개월 국채 할인수익률의 영업일 평균, 연율 %를 그대로 사용 |
| γ 심리 | [FRED / Cboe VIXCLS](https://fred.stlouisfed.org/series/VIXCLS) | 일별 종가 | 원값을 그대로 사용, 현재 뉴욕 날짜는 완료 봉으로 사용하지 않음 |

FRED의 `graph/fredgraph.csv`에서 2010년부터 전체 계열을 취득한다. 최초 구현 중 잘못 지정한 `graph/graph.csv`는404였고 기존 manifest의 실제 경로로 수정했다. 접근 제한을 우회하지 않았다. VIX는 이번부터 FRED/Cboe 전체 계열로 교체하며 이전 Yahoo 자료와 이어 붙이지 않는다. 원천별 관측 누락 차이로 보정창과 최신 표준화 값은 달라질 수 있다. GDP와 금리의 정의는 기존 FRED/BEA·연준 정의를 유지한다.

API 프로세스가 시작되면 15분마다 공식 최신값을 확인한다. 분기·월간 발표 전에는 이전 관측을 유지하며 장중 실시간 지표로 표기하지 않는다. 화면은 보이는 미국 시장에서 1분마다 DB를 다시 읽고, 탭 복귀 때도 다시 확인한다. 조회 시각·관측 기간·원자료 확보 시각을 구분한다. CSV에는 정확한 공표 시각과 당시 수정 전 판본이 없으므로 `releaseTimeKnown=false`를 유지한다.

새 자료가 먼저 수집되어 화면의 출처 해시와 다르면 ‘새 자료 반영 중’으로 표시하고 다시 읽는다. 새 자료의 확인 시각으로 이전 값이 최신 검증됐다고 표시하지 않는다. S&P 500 관측 가격 차트는 기존 별도 가격 계열을 보존하며 이 수집기가 SPX 장중 호가까지 제공하지는 않는다.

## DB·실패·동시성

`004_us_collection`은 수집 장부와 SHA-256 중복 제거 원응답 저장소를 추가한다. 세 원천을 모두 성공적으로 읽고 검증한 경우에만 새 시장 판본을 발행한다. 1MiB 제한, 20초 요청 제한, 고정 공식 URL·리다이렉트 거부, 헤더·날짜·정렬·중복·수치·기존 관측일 보존 검사를 적용한다. 현재 시점의 수정값은 허용하되 기존 보유 관측일을 지우는 응답은 거절한다.

수집기는 PostgreSQL 세션 advisory lock으로 한 소유자만 실행한다. 프로세스가 중간 종료된 수집은 다음 소유자가 `interrupted`로 남긴다. 성공 판본과 성공 수집 영수증은 같은 발행 트랜잭션에서 수락한다. 발행 compare-and-set이 충돌하면 다른 작업자의 변경을 덮어쓰지 않는다. 수락 응답이 불확실하면 같은 수집 ID의 저장 상태부터 대조한다.

같은 원자료/관측값이면 스냅샷을 새로 만들지 않고 `unchanged` 확인 기록만 남긴다. 일부 원천 실패나 파서·발행 오류는 `failed`로 남기고 기존 완전한 판본과 출처 시계를 보존한다. 화면 연결 실패 시 이미 읽은 최신 판본을 더 오래된 정적 저장본으로 되돌리지 않는다. 최초 오프라인 진입의 정적 저장본은 기존 봉인 자료이며 최신 실시간 판본으로 주장하지 않는다.

이전 시장 판본은 revision 조회로 남아 있고 국내/RSI/주가 계열과 별도 주택·테마 장부는 수정하지 않는다. 과거 자료로 당시 실시간 예측 성과를 재현했다고 주장하지 않는다.

## 실행과 점검

고정 Node24.22.2와 기존 PostgreSQL을 사용한다. `npm run start:api`는 기존001과 새004의 체크섬을 검증하고 수집기를 실행한다. `ATLAS_US_COLLECTION_ENABLED=0`은 명시적 비활성화이며 UI도 꺼짐을 표시한다. 운영 배포·OS 자동 시작·다른 계정/유료 API·브로커·주문은 추가하지 않았다. 앱/컴퓨터가 꺼진 동안의 상시 수집을 보장하지 않는다.

```sh
npm run typecheck
npm run build:web
npm run test:panels
TEST_DATABASE_URL=... npm run test:service
npm test
DATABASE_URL=... npm run collect:us
```

수동 `collect:us`는 명시적 한 번의 강제 확인이다. 일반 화면의 새로고침은 DB를 다시 읽고, 수집 주기를 우회하여 외부 요청을 연달아 보내지 않는다. 상태는 GET `/api/v1/market-lab/collection`, 계산은 GET `/api/v1/market-lab`의 `usDirection`과 기존 `diagnostics`로 조회한다. 원시 응답은 DB `market_lab_source_payloads`, 각 시도의 결과·해시는 `market_lab_collection_runs`에 보존한다.

실제 수집·표시·장애·보존 검증은 `us-direction-verification.json`을 참고한다. 외부 교차 검토, 원음 전사, 모형의 예측력 검증과 운영 배포는 별도 미완료 상태다.
