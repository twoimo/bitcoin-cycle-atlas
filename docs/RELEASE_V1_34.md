# v1.34.0 · 탐색과 분석 결과의 정보 구조

화면 전반의 탐색·입력·결과·문서 구성을 정리했습니다. 기존 v1.33.0의
먹색 바탕과 종이색 글자, 황동색 강조를 유지하면서 각 작업에서 무엇을
선택하고 어떤 결과를 읽는지 더 분명하게 보여 줍니다.

## 화면 변경

- 데스크톱 오른쪽 탐색 메뉴에 기존 한국어 이름을 표시합니다. 여섯
  목적지를 차트 도구와 구획하고 현재 위치를 명확히 보여 줍니다.
- 외곽 상단 한 줄 안에서 종목·화면 선택·현재 수치·보조 조작의 간격과
  글자 위계를 구분합니다. 넓은 화면에서는 실제 종목명과 티커를 함께
  표시하며 검색 결과의 이름·티커·거래소도 열로 정리합니다.
- 조건 실험과 현금흐름은 입력을 관련 항목별로 묶고 결과에 더 넓은
  공간을 배분합니다. 기존 계산의 지수·순현재가치를 우선 읽히게 하고
  기여도와 손익·현금 항목은 원장 구조로 보여 줍니다.
- 시장 진단 요약과 주택·RSI·테마의 보조 자료는 핵심 값, 관측·조건,
  원장·출처가 구분되도록 정렬합니다.
- 자산표의 과거 통계·현재 가격·판단 열, IPO의 날짜·상태·회사명,
  리서치의 제목·출처·절 제목·본문을 각각의 읽는 방식에 맞춥니다.

## 적용 기준과 보존

요청된 UI/UX Pro Max의 고정 revision
`b7d5353e0130feb8c5574ef1251f8a1db1873ccb`와 공통 지침을 읽고 적용했습니다.
검색 추천 중 금융 작업 화면에 맞는 모듈형 계층과 어두운 분석 화면의
원칙을 채택했습니다. 검색으로 맞는 구조를 얻지 못한 부분은 실제
소스·화면과 공통 지침으로 판단했으며 그 범위는 MASTER.md에 기록합니다.

기존 네 외곽 영역과 한 줄 조작부, 공통 종목 검색, 실제 스크롤과 고정
표 열, 대화상자의 닫기·Escape·포커스 복귀를 유지합니다. 관측 수치와
단위·결측, 계산식, 원장·리플레이, ztd-charts의 실제 차트와 좌표는
그대로입니다. 최신 자동 갱신 자료와 이전 릴리스의 수정도 보존합니다.

## 검증 범위

원본 전체 테스트, Chrome 상호작용, Hallmark 기존8개·통합10개 화면을
사용합니다. 이전 소스의 static60/core10/workspace3 WARN은 시작 기록이며
새 결과로 복사하지 않습니다. 원본 checker·baseline·데이터·판정을
바꾸지 않고 static 중복은 한 번만 집계합니다. 실제 완료 결과는 이
버전의 PR·CI·배포 기록 및 인계 문서에 남깁니다.
