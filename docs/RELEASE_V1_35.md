# v1.35.0 · TradingView 참조 작업대

2026-11-07 (Asia/Seoul). 사용자의 최신 요청에 따라 UI/UX Pro Max와
JCodesMore의 실제 `clone-website` 스킬을 적용했다. 원본의 상단·좌측·우측·하단
영역을 실제 화면과 computed style로 관측한 후 공통 화면을 변경했다.

## 화면 변경

- 우측 64px 글자 레일을 45px 아이콘 레일로 바꾸고 한국어 accessible name,
  현재 위치, 마우스·키보드 포커스 툴팁을 유지한다.
- 데스크톱은 상단 38px, 좌측 52px, 4px 구획 간격, 하단 38px로 맞춘다.
  휴대폰과 coarse-pointer 태블릿은 기존 44px 주 조작 영역과 48px 상단 행을 유지한다.
- 중립적인 검정·회색 표면, 시스템 글꼴, 얇은 구분선과 파란 UI 동작색을 적용한다.
  금융 곡선·상태·손익의 원래 색은 별도로 유지한다.
- 가격 표시 간격은 기존의 실제 native select를 데스크톱에도 사용한다.
  1m부터 1W까지 모든 원래 선택지·동기화·미확보 간격 거부 동작은 동일하다.
- 검색창을 최대 840 × 680px로 정리하고 종목명·티커·출처의 열과 키보드 이동을 유지한다.
- 시장·조건 실험·현금흐름·RSI·부동산·테마의 값·폼·표를 작고 일관된 밀도로 맞춘다.
  자산 비교·IPO·리서치에도 동일한 표면과 조작부를 적용한다.
- 리서치 본문은 하나의 읽기 열로 정리하고 상단 닫기와 내부 스크롤을 유지한다.

## 지시와 검사 도구 정리

사용자가 종료한 이전 디자인 검사기의 workflow·vendor·wrapper·전용 테스트를
제거했다. 활성 지시문과 코드 주석도 정리했고, 이전 결과와 증거는 보관 기록으로
분리했다. 기존 도구 전용 테스트 16개 감소를 제품 테스트 누락으로 집계하지 않는다.
[정리 기록](design-tool-retirement-2026-11-07/README.md)

## 보존 범위

기존 관측값, 계산식, 원장, 리플레이, source clocks, 의미 색상, ztd-charts와
원래 기능 소유권을 보존한다. 기존 내부 툴바는 복원하지 않는다. 스크롤바 표시를
숨기는 사용자 설정과 실제 wheel·touch·keyboard 스크롤은 유지한다.

[현재 디자인 기준](../design-system/bitcoin-cycle-atlas/MASTER.md)에 두 스킬의
고정 revision, 실제 관측값, 채택·거부한 검색 결과 및 대응 화면을 기록했다.
관측한 TradingView 화면은 1363 × 936 desktop이며, Atlas 고유 금융 기능과
어두운 차트 캔버스는 유지하므로 미확인한 100% 픽셀 일치를 주장하지 않는다.

## 검증과 공개

기존 production build, 수치·원장·formal 검증, React·service 테스트와 전체
53개 native Chrome 케이스를 릴리스 게이트로 사용한다. 데스크톱 간격 제어의
native 입력 경로만 실제 select에 맞췄으며 전체 케이스와 의미 assertions는 유지한다.
새 레일 툴팁의 키보드·포인터·짧은 화면 경계·모바일 억제 검사 3개를 추가했다.

최종 실행 결과, PR source와 실제 배포 source, 공개 화면 확인은 릴리스 후
인계 문서에 각 실행의 증거와 함께 기록한다. 이전 버전의 결과를 이번 결과로
인용하지 않는다.
