# 현재 차트의 간격과 주황색 예측선을 유지하는 봉 리플레이

BTC 차트에서 **↶ 봉 리플레이**를 누르면 **현재 화면의 주황색 미래 가정선과 갈색 범위를 그대로 고정**하고 실제 캔들을 프로젝트 시작일부터 공개합니다. 현재 표시 간격·기간·사이클 표시를 쓰는 기존 가격 차트에서 바로 재생합니다. 상단의 **1m–1W** 간격 도구와 하단의 **4년·6개월·장기 전망·전체** 기간 도구도 유지합니다. 좁은 화면에서는 같은 선택지를 원래의 간격·기간 선택 상자에서 사용할 수 있습니다.

**v1.29.4의 재생 도구는 차트 하단 중앙의 작은 막대**입니다. 차트는 원래 높이를 유지하고, 날짜·예측 설정·평가는 **Select bar** 안에서 펼칩니다. **종료 X는 차트 오른쪽에 따로** 있어 막대를 가로로 스크롤해도 그대로 접근할 수 있습니다. 이번 배치 변경으로 현재 주황색 경로·갈색 범위, 계산·출처 식별자·자료 확보 범위나 평가 기준을 바꾸지 않습니다.

기본 시작일은 **2026-10-21**입니다. 저장소 생성과 최초 앱 커밋이 같은 한국 날짜이며, 처음 연구에 쓰인 마지막 완료 일봉은 **2026-10-20 UTC**입니다. 처음에는 10월 20일까지 표시하고, **다음 봉**을 누르면 10월 21일 실제 캔들이 나타납니다. [시작일 근거·초기 원본·해시](PROJECT_REPLAY_ORIGIN.md)

현재 가정선을 과거에 이미 발행했던 예측으로 채점하지 않습니다. 당시 전망의 실제 결과를 비교하려면 **10월 21일 당시 전망** 또는 **보존 예측**을 선택합니다. BTC·ETH의 과거 재구성과 ETH·MSTR·BMNR의 기존 보존 예측 재생도 유지합니다. 기존 경제 가정이나 운영 기본 모형을 바꾸는 작업이 아니며, 예측 정확도·투자 수익률 개선을 주장하지 않습니다.

## 작은 재생 막대

막대의 왼쪽부터 다음 순서로 배치합니다. 각 아이콘의 이름과 기능은 툴팁과 접근성 이름으로 제공합니다.

| 도구 | 동작 |
| --- | --- |
| **처음으로** | 현재 세션의 처음 공개 위치로 되감습니다. 같은 고정 예측과 세션을 유지하며 모델을 다시 계산하지 않습니다. |
| **Select bar ▾** | 날짜·무작위·첫 사용 가능일과 가격 표시·예측 설정·이전 봉·진행 위치·평가를 엽니다. |
| **시작점 선택 화살표** · Select starting point | 파란 가위선으로 차트 위에서 새로운 시작점을 고릅니다. |
| **재생 / 일시정지** | 선택한 속도로 실제 봉 공개를 시작하거나 멈춥니다. |
| **다음 봉** | 확보한 다음 실제 일봉 한 개를 공개합니다. 주봉에서도 하루씩 갱신합니다. |
| **속도** · 1×, 10× 등 | 배율을 선택합니다. 구체적인 갱신 간격은 툴팁과 메뉴 안 설명에서 확인합니다. |
| **D** | **Auto · 1일** 업데이트를 뜻하는 잠긴 표시입니다. 차트의 일봉·주봉 간격과는 별개입니다. |
| **최신 차트 아이콘** | 저장 선택 창을 열고, 종료를 확정하면 원래 최신 차트로 복귀합니다. |

오른쪽에 분리된 **X**도 최신 차트 아이콘과 같은 종료 창을 엽니다. **처음으로**나 차트의 `End` 키와는 다른 동작입니다. 처음으로는 같은 세션의 처음, `End`는 확보한 마지막 봉으로 이동하며 둘 다 리플레이를 유지합니다. [실제 조작과 세션 처리](../dist/chart-replay.js) · [배치와 내부 스크롤](../dist/chart-replay.css)

## 사용 순서

1. 현재 BTC 가격 차트에서 **봉 리플레이**를 누릅니다. 저장된 세션이 없으면 **현재 예측선 고정**, **캔들**, **시작 2026-10-21**로 준비됩니다. **1D 또는 1W 중 현재 선택한 간격을 유지**합니다. 저장된 세션이 있으면 **이어서 · Continue**와 **새로 시작 · Start new** 중에서 고릅니다.
2. **다음 봉** 또는 **재생**을 누릅니다. 막대의 **D**는 확보한 실제 자료에 맞춘 **Auto · 1일** 업데이트입니다. 1D에서는 다음 실제 일봉을 공개하고, 1W에서는 공개한 일봉만으로 같은 주봉을 갱신합니다. **처음으로**는 같은 세션의 처음 위치로 되감고, **Select bar** 안의 **이전 봉**이나 위치 막대는 원하는 공개 위치로 되돌립니다.
3. 다른 시작점을 원하면 **Select bar 옆 화살표 · Select starting point**를 누릅니다. 재생 중이었다면 멈추고, 포인터를 따라 움직이는 파란 세로선과 가위 표시로 날짜를 미리 봅니다. **차트를 클릭하거나 탭하면 선택한 날짜의 직전까지 절단**하고, 다음 업데이트부터 선택한 날짜를 공개합니다. **선택 취소** 또는 `Escape`는 기존 확정 위치를 유지합니다.
4. **Select bar ▾**를 열면 **날짜 선택 · Select date**, **무작위 봉 · Random bar**, **첫 사용 가능일 · First available day**와 날짜 입력이 함께 나옵니다. **Select date**를 누르면 날짜 입력으로 화면과 초점이 이동하며, 날짜 입력 뒤 `Enter` 또는 **이 날짜 시작**으로 확정합니다. 가격 표시·예측 종류·해당 모드의 예측 기간도 이 메뉴에서 바꿉니다. 현재 주황색 예측선의 원래 기준일과 값은 시작점 선택으로 이동하거나 재계산되지 않습니다.
5. **Select bar → 평가·근거**에서 지금 보는 가정의 기준일과 실제 관측의 출처를 확인합니다. 기본 현재선 모드는 시각 비교이며 과거 적중률을 표시하지 않습니다. **공개된 평가 JSON**은 고정 경로·식별자와 현재까지 공개한 실제값만 내보냅니다.
6. 막대 끝의 **최신 차트 아이콘** 또는 오른쪽의 **X**를 누르면 종료 창이 열립니다. **현재 세션 저장**을 체크하고 **종료**를 누른 경우에만 저장합니다. 체크를 해제하면 이번 진행을 저장하지 않고 기존 저장본을 유지합니다. **계속 보기**는 종료를 취소합니다. 다음에 **Continue**를 고르면 저장된 공개 날짜에서 일시정지 상태로 재개합니다.

Select bar 안에서는 `Tab`과 `Shift`+`Tab`으로 버튼·날짜·선택 상자·위치 막대를 이동합니다. 입력의 방향키는 브라우저의 기본 동작을 유지합니다. `Escape` 또는 메뉴 오른쪽 닫기로 메뉴를 닫으면 **Select bar** 버튼으로 초점이 돌아갑니다. 세 가지 시작 봉 선택 버튼에 초점이 있을 때만 `↑`·`↓`·`Home`·`End`로 그 버튼들 사이를 이동합니다.

**BTC 축소 추세 · 회고** 또는 **ETH 가격 모형 · 회고**를 선택하면 기존의 차트 클릭·날짜 입력·무작위 기준일 선택을 사용합니다. 이 경우에만 선택 기준일까지의 자료로 비교용 모델을 새로 계산합니다. ETH·MSTR·BMNR의 조작은 기존 자산별 재생 방식입니다.

실제 자료가 없는 날이나 주식 휴장일을 새 봉으로 만들지 않습니다. 분·시간 자료가 없는 간격에서는 미확보 사실을 표시합니다. 라이브 차트에서 1m 등 미지원 간격을 선택한 상태로 리플레이를 열면 해당 간격을 유지한 채 진입을 거부합니다. 이미 1D/1W 리플레이 중이면 미지원 간격 선택을 거부하고 현재 간격과 공개 위치를 유지합니다. 일별 종가를 분봉으로 쪼개거나 간격을 자동으로 1D로 바꾸지 않습니다.

### 1W는 실제 일봉의 공개 범위로 형성됩니다

BTC 주봉은 **UTC 월요일부터 일요일까지**입니다. 수요일까지만 공개했다면 월·화·수의 실제 Bitstamp OHLC와 거래량만 합칩니다. 시가는 월요일의 실제 시가, 고가와 저가는 공개된 날짜의 극값, 종가는 마지막 공개일의 실제 종가, 거래량은 공개된 날짜의 합입니다. 다음 일봉을 공개해도 **같은 주봉의 월요일 가로 위치와 시가는 유지**됩니다. 아직 공개하지 않은 목·금·토·일의 고가·저가·종가·거래량은 사용하지 않습니다.

| 보존 자료를 공개한 위치 | 주 시작 | 시가 | 고가 | 저가 | 종가 | 공개 일수 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 2026-10-21 UTC | 2026-10-19 | 82,001.58 | 84,842.65 | 81,102.28 | 84,023.24 | 3 |
| 다음 1일: 2026-10-22 UTC | 같은 2026-10-19 | 82,001.58 | 84,842.65 | 80,835.75 | 81,315.35 | 4 |

이 예시는 [보존 Bitstamp 일봉](../dist/data/btc-volume.json)의 해당 날짜들을 합산한 값이며, 사용자가 참고한 TradingView의 다른 날짜·가격 예시를 Atlas 값으로 복사한 것이 아닙니다. 완료 전에는 **형성 중 주봉**과 공개 일수를 표시하고, 일요일까지 확보·공개한 뒤 완료 주봉으로 표시합니다. 주 시작부터 필요한 실제 일봉이 누락된 구간은 정상적인 주봉처럼 합성하지 않습니다. [집계와 자료 경계](../dist/forecast-replay.js)

**첫 사용 가능일**은 실제 원자료의 범위에서 정합니다. 현재 보존본의 일봉 첫날은 **2011-08-18**, 주봉을 시작할 수 있는 첫 월요일은 **2011-08-22**입니다. 일봉 첫날의 직전 상태는 실제 관측이 없는 빈 프레임으로 두고, 다음 업데이트에서 실제 첫 봉을 공개합니다. 그 전날의 가짜 종가나 시가를 만들지 않습니다. 오래된 시작점을 골라 현재 예측선이 화면 밖에 있을 때도 원래 현재 날짜에서 시작하는 경로를 보존하며, 과거 날짜에 가짜 주황선 구간을 붙이지 않습니다.

### 재생 속도

속도는 **실제 일봉 한 개를 추가로 공개하는 간격**입니다. 1W에서도 이 간격마다 주봉 안에 하루가 추가됩니다. 막대에는 **1×·10×**처럼 짧은 배율만 표시하며, 속도 선택의 툴팁과 **Select bar** 안의 속도 설명에 실제 갱신 간격을 표시합니다. 메뉴의 **D · Auto 1일** 설명도 주봉에 하루씩 추가한다는 같은 의미입니다.

| 선택 | 업데이트 간격 | 의미 |
| --- | ---: | --- |
| 0.3× | 3,000ms | 3초마다 1회 |
| 0.5× | 2,000ms | 2초마다 1회 |
| 1× | 1,000ms | 초당 1회 |
| 2× | 500ms | 초당 2회 |
| 4× | 250ms | 초당 4회 |
| 8× | 125ms | 초당 8회 |
| 10× | 100ms | 초당 10회 |

0.3×는 요청한 **3초 간격**을 명시적으로 사용합니다. 매번 화면을 그린 뒤 같은 시간을 다시 기다리는 방식으로 지연이 누적되지 않도록 다음 갱신 예정 시각을 기준으로 대기 시간을 계산합니다. 브라우저가 백그라운드로 이동하면 자동 재생을 멈추며, 늦게 도착한 타이머가 여러 봉을 한꺼번에 공개하지 않습니다. [재생 상태와 시간 계약](../dist/chart-replay-state.js)

| 조작 | 동작 |
| --- | --- |
| `Shift` + `↓` | 재생 / 일시정지 |
| `Shift` + `→` / `←` | 다음 / 이전 실제 봉 |
| 차트에 초점이 있을 때 `Space`, `→`, `←` | 재생 / 일시정지, 다음 / 이전 봉 |
| 차트에 초점이 있을 때 `Home` / `End` | 기준일 / 확보한 마지막 봉 |
| `Escape` | 시작점 선택 중에는 선택 취소; Select bar 안에서는 메뉴 닫기, 일반 재생 화면에서는 종료 확인 열기 |
| 차트 드래그 / 휠 | 표시 기간 이동 / 확대·축소 |
| 날짜·선택 입력 | 브라우저의 기본 키보드 조작 유지 |

다른 탭이나 창으로 이동하면 자동 재생을 멈춥니다. 휴대전화에서는 재생 막대의 조작 영역을 **44px**로 두고 한 줄 안에서 가로로 밀어 나머지 도구에 접근합니다. **X는 막대의 가로 스크롤 바깥**에 유지합니다. Select bar 메뉴는 화면 안의 높이로 제한하고 내부에서 세로로 스크롤하며, 메뉴 제목과 닫기 버튼은 상단에 유지합니다. 기존 BTC의 상단 간격과 하단 **4년·6개월·장기 전망·전체** 도구는 별도로 계속 사용합니다.

## 현재선 보기와 당시 예측 평가의 차이

| 종류 | 대상 | 무엇을 비교하는가 | 의미의 한계 |
| --- | --- | --- | --- |
| **현재 예측선 고정** · 기본 | BTC | 열기 직전 화면의 현재 주황색 경로를 유지하면서 10월 21일부터 Bitstamp 실제 캔들 공개 | 현재 경로는 과거 발행 기록이 아닙니다. 날짜를 과거로 이동하거나 과거 적중률을 계산하지 않습니다. |
| **10월 21일 당시 전망** | BTC | 첫 앱 커밋의 3년 기본 경로와 현재 판본의 Coin Metrics 일말 관측 | 당시 실제 보존한 초기 모형이며 현재 장기 모형과 다릅니다. 커밋 시각을 실제 웹 게시 시각으로 간주하지 않습니다. |
| **BTC 축소 추세 · 회고** | BTC | 기준일까지의 자료만으로 새로 계산한 축소 추세 기준모형과 이후 실제 가격 | 당시 Atlas 장기 예측을 발행했던 기록이 아닙니다. |
| **ETH 가격 모형 · 회고** | ETH | 기준일까지의 자료만으로 계산한 선택된 ETH 가격 모형과 이후 실제 가격 | 현재 코드와 현재 보존 판본을 사용한 과거 재구성입니다. 모형별 최소 자료 조건을 만족해야 합니다. |
| **보존 예측** | BTC·ETH·MSTR·BMNR | 해시 검증을 통과한 기존 예측 기록의 경로와 실제 가격 | 기록에 보존된 기준일·경로만 재생합니다. 실제 결과가 아직 없으면 평가 대기입니다. |

**첫 공개 봉**, **예측이 원래 시작하는 날짜**, **현재 공개 위치**는 별개입니다. 기본 모드에서 첫 봉이 10월 21일이어도 현재 예측선은 화면에 원래 표시된 기준일에서 시작합니다. 사이의 빈 날짜에 가짜 예측값을 채우지 않습니다. 다음 봉으로 이동하거나 속도·표시 유형을 바꿔도 경로를 다시 적합하지 않습니다. 당시 전망은 원래 2026-10-20~2029-10-21의 1,098개 점을 보존합니다. 한 경로에서 비교한 여러 일봉을 독립적인 예측 횟수로 세지 않습니다.

메인 차트는 현재 보존 판본의 **시장 날짜 기준 회고 비교**입니다. 해당 날짜 당시 실제로 수집할 수 있었던 판본을 모두 확보했다는 뜻이 아닙니다. 기존 예측 기록 엔진의 정보 수집 시각 검증 및 엄격한 정보 시각 모드는 유지하지만, 이번 메인 차트의 관측 날짜 재생을 그 모드의 검증 결과로 바꾸어 표시하지 않습니다.

ETH에서 국면 적응 모형에 필요한 확정 상승·하락 수익률 표본이 각 30개 미만이면 한국어로 이유를 표시하고 예측 생성을 멈춥니다. **통합 변동성으로 같은 날짜 비교**를 직접 누르면 기준일·예측 기간·관측 자료를 그대로 유지하고 모형만 바꿉니다. 미래의 국면 판정을 과거로 소급하거나 자동으로 모형을 바꾸지 않습니다. ETH의 공통 날짜 선택은 통합 변동성 모형에 필요한 366번째 관측부터 가능하며, 국면 적응의 추가 조건은 선택일 당시의 표본으로 판단합니다.

## 미래 실제값을 숨기는 경계

- 기준일 뒤의 실제 관측은 공개 위치까지 잘라서 렌더러에 넘깁니다. 과거 가격을 그리는 데 필요한 전체 이력은 엔진의 비공개 저장소에서 관리하며, 기존 예측 기록의 90일 입력 배열·출력 해시를 바꾸지 않습니다.
- 가격축은 공개한 실제 가격과 허용된 고정 예측으로 계산합니다. 아직 공개하지 않은 실제 고점·저점으로 축을 맞추지 않습니다.
- BTC 현재 차트 모드는 기존 가격축과 사이클 레이어를 사용하며, 현재 가정으로 만들어진 주석을 과거의 확정 정보로 표시하지 않습니다. 실제 관측에 관한 표시와 캔들은 공개 위치를 따릅니다. 재생 중 새 라이브 모델·자료 응답·상세 대화상자·명령 검색이 선택한 고정 경로를 덮지 않도록 제어합니다. 다른 평가 모드에서는 기존의 미래 실제값·사후 표시 차단을 유지합니다.
- 캔들은 검증된 실제 OHLC만 사용합니다. 주간 집계는 **먼저 공개 시점으로 자른 뒤**, 필요한 시작일부터 자료가 이어진 완료 주 또는 형성 중인 주를 만듭니다. 그 주의 미래 일봉이나 나중에 완성된 주봉 값을 가져와 자르지 않습니다.
- 파란 가위선은 확정 전 미리보기입니다. 기존의 흰색 공개 위치와 실제 가격·거래량·지표는 클릭 전까지 그대로이며, 확정 직후 새 공개 위치 뒤의 실제값을 함께 숨깁니다. 미래의 주황색 가정값이 가격축에 포함되는 것은 의도한 동작입니다.
- 내보내기는 현재 프레임을 사용합니다. 원본 결과 파일 전체나 아직 공개하지 않은 미래 실제 가격을 JSON에 넣지 않습니다.

리플레이 UI의 정보 경계이며, 공개 정적 사이트의 원자료 파일에 대한 접근 통제는 아닙니다.

## 지표 읽기

**현재 예측선 고정** 모드는 현재 가정선과 실제 캔들의 시각 비교입니다. 이 모드에서는 오차·적중률을 표시하지 않으며 내보내기의 평가 수치도 채우지 않습니다. 아래 지표 설명은 당시 보존본·보존 예측·과거 재구성의 비교에 해당합니다.

**평균 절대 % 오차**는 현재까지 실제값과 대응한 예측 가격의 상대 오차입니다. **가격 유지 대비 개선**은 같은 비교 대상의 절대 로그 오차를 기준일 가격 유지 모형과 비교합니다. 양수이면 이 기준모형보다 오차가 작았다는 뜻입니다. 분모가 0이거나 로그 비교가 불가능한 값은 없는 점수로 처리하며 임의로 좋은 점수를 채우지 않습니다.

**방향 일치**는 같은 기준일 가격에서 실제값과 예측값의 변화 방향을 비교합니다. 비교한 일봉 수, 아직 결과가 없는 목표 수, 자료가 미확보인 목표 수를 함께 표시합니다. 이 점수들은 단일 고정 경로의 회고 결과이며 거래 비용·실행 가능 수익·통계적 독립성·미래 성능을 입증하지 않습니다.

## 세션과 실패 처리

자산별로 기준일, 모형·기간·기록 ID, 공개 날짜, 간격·표시 기간·차트 유형, 재생 속도, 예측 출력 해시와 관측 출처 해시를 현재 브라우저에 저장합니다. 배열 위치만 저장하지 않으므로 자료가 보충되어도 같은 날짜로 돌아갑니다. 예측 출력이 바뀌었으면 **Continue를 거부하고 기존 저장본을 보존**하며 명시적인 새 시작을 요구합니다. 같은 예측에 실제 관측 판본만 갱신되었으면 그 사실을 표시합니다.

현재선 모드의 출력 해시는 열 때 고정한 현재 경로를 식별합니다. 재생 세션이 열린 동안의 경로 고정과, 페이지를 다시 열었을 때 갱신된 현재 경로를 확인하는 절차를 구분합니다. 시작일만 저장해 나중의 다른 모델을 예전 경로로 부르지 않습니다.

재생·이동·속도 변경·가위 미리보기·시작점 확정·Start new는 현재 탭의 임시 상태만 바꿉니다. **저장 체크 + 종료 확정**이 유일한 저장 시점입니다. 종료 취소와 체크하지 않은 종료는 이전 저장 문자열까지 그대로 유지합니다. 저장 공간이 막히면 실패를 표시하고 현재 세션을 유지하며, 저장 체크를 해제하면 저장 없이 종료할 수 있습니다. [실제 UI와 저장 정책](../dist/chart-replay.js)

이 기능은 차트의 과거 봉을 검토하는 리플레이입니다. Replay Trading, 모의 주문, 포지션·손익 계산, 브로커 연결 기능은 포함하지 않습니다.

기준일 선택·자료 로드·타이머마다 소유 세대를 부여합니다. 이전 요청이 늦게 끝나거나 취소를 무시해도 현재 세션을 덮지 않습니다. 오류가 나면 이전 차트를 지우고 멈춘 상태로 이유를 표시합니다. 자료가 없거나 무결성 검증에 실패했을 때 다른 자산·오래된 자료로 조용히 대체하지 않습니다.

## pstack 적용과 검증

공식 pstack의 [행동을 검증하는 테스트](https://github.com/cursor/plugins/blob/main/pstack/skills/principle-test-behavior-not-implementation/SKILL.md), [실제 산출물로 작동을 입증하기](https://github.com/cursor/plugins/blob/main/pstack/skills/principle-prove-it-works/SKILL.md), [공유 상태를 먼저 분리하기](https://github.com/cursor/plugins/blob/main/pstack/skills/principle-separate-before-serializing-shared-state/SKILL.md)를 적용했습니다. 엔진·상태전이·렌더러/브라우저 검증을 병렬로 분담하고, 통합부의 오래된 응답·저장 시점·네이티브 입력 문제를 별도로 교차 검토했습니다.

- **엔진 행동:** 미래 실제값을 극단값으로 바꾸어도 기준일 예측과 이전 프레임이 같아야 합니다. 공개 시점·실제 OHLC·빈 날짜·정보 시각·주간 집계 경계를 확인합니다.
- **상태전이:** 실제 JavaScript controller에서 시작·중지·되감기·속도 변경·오래된 타이머의 소유를 검사합니다. 기존 길이 4의 명령 조합 10,000개와 요청 세대·타이머 세대·세션 동결을 각각 제거하는 세 변이 검증은 별도 기록으로 유지합니다. [모형·원시 receipt·한계](replay-state/README.md)
- **실제 coordinator:** 늦은 자료·기록 응답, 선택 옵션의 고정, 날짜 기준 세션 복원, 네이티브 입력 키, 숨겨진 문서의 자동 정지를 검사합니다.
- **렌더링:** 공개된 실제값과 실제 OHLC만 표시하는지, 0 예측이 유지되는지, 작은 화면 축과 많은 캔들의 극단값이 보존되는지 확인합니다. ETH 전체 모듈 그래프가 BTC 전용 분석 모듈을 가져오지 않는 기존 검사를 유지합니다.
- **실제 브라우저:** BTC 세 화면, ETH 두 화면, MSTR·BMNR 각 한 화면에서 네이티브 입력·동일 SVG·진행/정지·고정 예측 JSON·실제 OHLC·최신 복귀·재개를 확인합니다. 실행별 결과와 스크린샷은 브라우저 검증 receipt에 기록합니다.
- **패키징:** 원래 보존 예측·자료 바이트와 모듈 연결을 유지하고 새 CSS를 단일 HTML에 포함합니다.

유한 상태 검사는 무한 상태공간에 대한 형식 증명이 아닙니다. 실제 Chromium 검사는 실물 모바일 기기·iOS Safari 전체 검증으로 확대하지 않습니다. 자료 인과성·화면 정확성 검증은 금융 예측 성능의 증명이 아닙니다.
