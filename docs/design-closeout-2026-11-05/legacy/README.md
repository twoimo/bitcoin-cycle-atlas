## Design choices considered

1. Explicitly hide already-closed disclosure bodies. Rejected: it would duplicate native hiding without improving the control and reading-region ownership.
2. Let the native summary own its control frame and focus ring; give the expanded research content its own padded reading region and hierarchy rule. Selected. It preserves the `details`/`summary` elements, native toggle behavior, all document nodes, source URLs, controls and values. Nested timing disclosures follow the same rule.
3. Replace native disclosure with custom buttons/regions. Rejected: it would add state and keyboard behavior without a product need.

Source links now wrap as a group while each unchanged link remains a one-line44px target. Scroll containers are named and keyboard focusable, including method tables created when an analysis tab first opens. Table row identities remain pinned. At mobile widths, the row identity occupies at most40% of its actual scrollport and any value at most60%; text wraps without deleting data. This accounts for narrower nested method regions, retains native horizontal scrolling and lets the last value be read alongside its row identity. The700px timeline canvas remains intact.

The legacy chart toolbar keeps its controls on one native horizontal row. The mobile cycle legend uses one readable column, and timing readouts use two columns. The formula surface explicitly owns `color:var(--text)` alongside its existing background token.
