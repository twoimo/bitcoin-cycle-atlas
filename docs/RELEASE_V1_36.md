# v1.36.0 · 하나의 가격 차트

사용자의 2026-11-07 요청에 따라 우측 탐색의 가격 차트와 종목 차트를
가격 차트 하나로 합친다. BTC·ETH·MSTR·BMNR·TQQQ·SOXL·233740·HYPE와
부산·서울·경기·전국 아파트는 같은 종목 검색에서 선택한다.

## 화면과 조작

- 시장 분석·리서치·자산 비교·공모주에서 가격 차트로 돌아오면 마지막으로
  선택한 종목을 복원한다. 기존 종목 링크와 지역별 URL은 유지한다.
- ETH와 두 주식은 기존 가격·전망 데이터 소유자를 유지하면서 BTC와 같은
  상단 행, 좌측 도구, 좁은 45px 우측 레일과 하단 기간·축 조작부를 사용한다.
- HYPE와 부동산은 공통 크기 측정·축·포인터 제어를 사용한다. 가격축, 시간축,
  이동·확대, 선택·측정, 설정, 날짜 이동과 이미지 내보내기가 선택 종목에 귀속된다.
- HYPE 근거·판정, ETF RSI·백테스트, 부동산 분석·월별 기록과 출처는
  기존 계산을 유지하며 해당 종목의 도구에서 접근한다.

## 실제 자료와 상태

HYPE 가격은 USDC, 주식·해외 ETF는 USD, 국내 ETF는 KRW,
부동산 가격은 월별 실거래가격지수로 표시한다. 부동산 거래량과 가격지수의
마지막 공표월은 별도로 유지한다. 미공표 가격은 결측으로 남기며 일봉·OHLC로
변환하지 않는다. 제공하지 않는 간격과 신호는 활성화하지 않는다.

차트 조작 메시지는 실제 활성 프레임·출처·종목·탐색 세대로 제한한다.
다른 종목이나 지난 탐색의 응답은 현재 도구·날짜·단위를 덮어쓰지 않는다.
종목을 떠날 때 보존한 가격 차트 상태와 독립된 분석 기록은 유지한다.

## 검증

라우팅·선택 종목 보존, 프레임 소유권, 자료 단위·월별 기능 제한과 실제
포인터·키보드 조작을 검증한다. 기존 수치·원장·리플레이 검사를 유지하고
production build와 생성된 Pages 자원을 확인한다. 실행 결과는 해당 커밋과
CI 실행에 귀속하며, 이전 버전의 성공 결과를 이번 변경의 결과로 사용하지 않는다.
