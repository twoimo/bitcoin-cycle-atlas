# v1.31.0 · 차트 워크벤치와 시점 고정 백테스트

기존 차트의 상하좌우 패널을 유지하면서 중앙에서 시장·조건·현금흐름·삼플레/RSI·부동산·테마 자료를 전환합니다. 시장 분석을 React 프론트엔드, API, PostgreSQL 저장소와 공통 계산 패키지로 분리했습니다.

- 삼플레/RSI: TQQQ·SOXL·KODEX 233740의 보존 일봉과 Buy/Sell·회고 백테스트, 확대/축소·드래그·종목별 도구를 연결했습니다.
- 기준시점 백테스트: 선택 시점 이후 자료를 예측 입력에서 제외하고, 고정한 경로를 이후 실제 가격과 비교합니다. 월말별365일 경로를 보존하고30·90·180·365일 성적 및 기존 봉 리플레이로 연결합니다.
- 거시 시계: 거시 날짜 기준점과 예시 경로 극값을 구분하고, 과거 분포·가정 민감도와 무보정/보정 날짜 오차를 표시합니다. 2010년부터 분기말65개·과거 목표3사이클을 검토하며 초기 근거 부족과 미종료 구간을 별도로 표시합니다.
- 부동산: 공식 매매 거래량·실거래가격 지수의 관계와 평균 거래량 상회/하회 구간의 후속 성과를 비교합니다.
- 테마·재료: 연기신 기준, 근거 타임라인, 차트 표식과 판정 이후 성과를 연결하며 하이퍼리퀴드를 첫 사례로 제공합니다.
- 미국 시장: 기존 알파·베타·감마 계산을 유지하고 곱값 방향과 출처·수집 상태를 표시합니다. 서비스 실행 중의 수집과 저장 스냅샷 사용을 구분합니다.
- 수집기를 중단하면 늦게 확보된 DB 연결 뒤의 원천 요청도 시작하지 않도록 취소 경계를 보완했습니다.
- 대기 중인 영역에 로컬 Skullet 스켈레톤을 적용하고 빈 자료·오류·재시도를 유지했습니다.

## 검증과 범위

릴리즈 준비 전 전체 회귀2,461개가 통과했습니다. 거시 시계의23개 영향 검사, Python 독립 검산, 실제 IAB 데스크톱/모바일과 오류·재시도·지연 결과 거절을 확인했습니다. 기존 월말 고정본13개 및 계산 모듈·네방향 패널 보존을 검증했습니다. 세부 소스 해시와 관측 시점은 `docs/architecture-migration/*-verification.json`을 따릅니다. 원격 릴리즈 검사 결과와 정확한 소스 커밋은 릴리즈 실행 기록에서 별도로 확인합니다.

과거 검증은 현재 보존 가격 판본의 시점 제한 회고입니다. 당시 발행 기록이나 정확한 역사 빈티지, 일반적인 예측 우월성을 입증하지 않습니다. 보정식과 확인 조건을 유지하면 무보정은2개 사이클, 보정의 동일 원점 비교는1개 사이클에서만 가능합니다. 미래 가격 경로와 민감도 범위는 조건부 가정이며 확률 구간이 아닙니다. 기존 ETH 후보 모형의 성숙 전향 증거·운영 승격 조건과 사용자 제외 외부 검토 상태를 유지합니다.

## 배포 파일과 서버 실행

GitHub 릴리즈는 현재 브랜치의 전체 소스와 기존 오프라인 HTML·연구/예측 원장 패키지를 제공합니다. 서버용 프론트엔드와 PostgreSQL/API 소스는 소스 ZIP에 포함됩니다. 독립 HTML과 GitHub Pages가 PostgreSQL·API·수집기를 실행하는 것은 아닙니다. 별도 운영 서버·DB·비밀값·계좌 연결은 구성하지 않습니다. 공개 Pages의 기본 브랜치를 이 릴리즈 브랜치로 바꾸지 않습니다.

서버 실행 및 DB 마이그레이션/자료 import 절차는 `docs/architecture-migration/README.md`를 따릅니다. `npm ci --ignore-scripts`, `npm run build:web`로 고정 의존성과 프론트엔드를 준비한 뒤 승인된 DB 환경을 사용합니다. 키움 주문·실시간 호가·상시 운영 수집을 제공한다고 주장하지 않습니다.


## v1.31.1 · GitHub Pages 정적 연결

사용자 승인에 따라 main 병합과 Pages 배포를 준비합니다. React의 7개 중앙 페이지와 공통 진입점을 프로젝트 하위 경로에 빌드하고, 딥링크 접속·새로고침에서도 기존 차트의 상하좌우 패널을 재사용합니다. 서버 모드의 API/DB 연결은 유지하며 Pages는 실제 저장 자료임을 표시합니다. RSI 백테스트는 서버와 같은 공통 계산 함수를 사용합니다. Pages에서 자동 수집·판정 저장·DB 운영을 실행한다고 표시하지 않습니다.

소스 빌드와 정적 산출물의 정확한 일치를 CI/Pages/Release에서 검사합니다. 월말 계산 파일19개는 v1.31.0과 바이트가 같고, 전체2,461회귀·패널55개와 정적 하위 경로 검사를 통과했습니다. 원격 검사와 배포 화면 검증의 최종 상태는 해당 커밋의 Actions 실행 기록을 따릅니다. v1.31.0 태그·자산은 변경하지 않습니다.

Pages 저장본에도 기존 검증 판본의TQQQ·SOXL·233740 전 기간 가격과 실제OHLC를 포함합니다. 원천 시각·응답 해시·현재 빈티지 한계를 보존하며 기존5개 시장 가격과 거시축은 바꾸지 않았습니다.


## v1.31.2 · 호스팅 경로와 최신 자료 회귀 검사

Vite 개발 서버의 /@fs 경로를 API 루트로 오인하지 않게 했습니다. 정적 화면 전환 전 아이콘 URL을 고정해 하위 페이지 이동으로 잘못된 위치를 요청하지 않게 했습니다. 기존v1.31.1 Pages/Release의2,462전체 회귀·수치·형식 검사는 통과했습니다. 별도CI의 DB 테스트에 남아 있던 Nov3 오전 시각과 SOXL 미보유 가정을 실제 보존 판본 이후의 시간·명시적 결측 판본으로 바꾸고, 신규·구판 동시 게시와 원복까지 격리 PostgreSQL22개로 재검증했습니다. 계산·관측 값·출처 시각·예측 기록은 바꾸지 않았습니다.
