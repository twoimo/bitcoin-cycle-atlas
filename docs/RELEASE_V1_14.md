# v1.14.1 — 성능·수치 경계·입력·상태 재시도 개선

전체 화면과 계산·비동기 상태를 심층 감사하고 재현한 결함과 병목을 수정했다. pstack 병렬 검토, 실제 코드 회귀, 제한된 TLA+ 모델과 반례, 실제 Chromium 검증을 함께 사용했다.

- 이동 통계를 분할상환 O(n)으로 바꾸고, 기하평균 경계의 가격 단위 의존성과 극단 수치 오차를 수정했다. `asOf` 뒤의 잘못된 값이 유효한 과거 결과를 차단하지 않게 했다.
- 명시적 새로고침이 이전 과거 캔들 조회 실패 대기를 해제한다. 기존 봉을 유지하는 실패 경로에서도 재시도가 가능하다.
- 터치 추적의 중복 미리보기를 프레임당 최신 위치 하나로 줄였다. 연구 창·상세 패널은 놓는 마지막 좌표를 적용하고 취소·숨김·capture 상실을 정리한다.
- 외부 글꼴 실패가 필수 CSS 실패로 전파되어 앱 전체를 막던 문제와 가로 휴대전화의 목록 기본 접힘을 고쳤다.
- 독립 실행 HTML의 중첩 모듈 data URL을 평평한 import map으로 바꿨다. 같은 통합 코드·자료에서 **17,432,498→3,280,279바이트**, 모듈 76개·관측 5,941개를 유지했다. import maps를 지원하는 최신 브라우저가 필요하다.

**로컬 검증:** 테스트 파일 74개, Node 러너 집계 662개 통과(실패·취소·건너뜀 0). 정적 경로·사이클 산출물·렌더러 작업량·standalone 원문/의존 그래프 검사와 두 형식 모델·두 실제 코드 mutation 검사 통과. Chromium의 글꼴 차단 7개 화면, 정상 한국어 글꼴 4개 화면, `file://` 독립 실행 2개 화면도 통과했다. 실물 Android/iOS·Safari·native 동시 pinch와 전체 사용자 입력 지연은 검증 범위 밖이다.

Node 24.19.0의 동일 입력·전후 각 5회 교대 실행에서 관측+미래 국면 계산 중앙값은 **187.62→49.44ms**, 운영 128경로 장기 엔진 전체는 **487.63→370.33ms**였다. 범위·소스 해시·원시 결과는 [심층 감사 보고서](DEEP_AUDIT_2026-10-24.md)에 보존한다. 이 수치는 순수 계산 시간이며 FPS나 가격 예측력 개선이 아니다. 경제 가정과 시장 원자료를 바꾸지 않았다.

# v1.14.0 — 간결한 모바일 차트와 조작

모바일에서 가격을 가리는 정보를 줄이고, 값 목록·연구 창·하단 도구가 기존 차트 영역을 나누어 사용하도록 개선했다. D-day UI는 제거했으며 장기 경제 가정과 사이클 계산 모형은 유지한다.

## 변경

- D-day HUD·지표 항목·진입점 제거. 옛 공유 링크와 저장 지표 구성에서도 해당 UI가 되살아나지 않는다.
- 모바일의 가격·여섯 색 범례 묶음 숨김: 폭 620px 이하, 또는 폭 950px 이하이면서 높이 500px 이하. 색 원과 기간선 자체는 각각의 표시 설정을 따른다.
- 데스크톱 가격 범례는 크기가 제한된 SVG로 관측 가격선·완료 캔들을 구분. 혼합 구간은 실제 보이는 두 종류와 자료별 종료일을 표시하며 관측 종가를 실시간 현재가로 부르지 않는다.
- 거래량은 새 접속·초기화에서 숨김으로 시작. 사용자가 명시적으로 저장한 표시 선택은 유지한다.
- 좌상단 값 목록은 이름·값 한 줄과 내용에 맞는 폭으로 간소화. 전체 접기, 목록 높이 선택, 내부 스크롤을 제공하고 터치의 설정·눈·삭제 조작을 유지한다.
- 목록과 연구 창의 공간을 함께 계산하고 짧고 넓은 화면은 가로로 나눈다. 여러 연구 창은 선택·이동으로 접근하며 최소화·숨김·삭제·최대화·독립 축을 보존한다.
- **차트 집중 보기 → 정보 다시 표시**로 정보를 일시 감추고 복원. 저장된 지표·창 상태를 바꾸지 않는다.
- 주요 사건·기간·날짜 이동·축·상태를 한 줄 하단에 통합. 모바일 기간 선택과 더보기, 위로 펼치는 사건 목록으로 추가 조작에 접근한다.
- 모바일 트레이의 SVG 크기·닫기, **차트 내보내기**, **작업 화면·공유** 진입점을 정리. 가상 키보드에 대응하는 대화상자 높이와 고정 제목·저장 영역을 적용한다.
- 폭에 맞는 가격축 여백·숫자 표시를 일·시간·빈 차트와 export에 연결. 20개 합성 포인터 회귀로 드래그 마지막 좌표, 축·값 추적·pinch 전환과 취소를 보강한다.
