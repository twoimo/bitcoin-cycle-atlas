# v1.28 · 자산군별 판단 이력

## 기능
- 기존 철도 전광판형 비교표에 판단 이력 진입점을 추가하고, 헤더를 분석 연도 수 / 연초→최고 종가 평균 상승률 / 연초→최저 종가 평균 하락률로 명확히 합니다. 평균 하락률은 MDD가 아닙니다.
- 위험 13·안전 4·대체 1, 총 18개 종목의 날짜별 분류와 유지 구간을 자산군별로 조회합니다. 1년·5년·전체 기간, 날짜·키보드 이동, 종목 상세와 일별 CSV를 제공합니다. 합성 자산군 매수·매도 신호는 만들지 않습니다.
- 과거 재계산은 현재 보관 원자료 버전으로 계산한 결과입니다. 당시 공급자 원본·운영 판단·장 마감 당시 이용 가능성·거래 수익성을 복원한 기록이 아닙니다. 휴장일·표본 부족·결측·자료 지연을 중립으로 채우지 않습니다.
- 실제 저장 스냅샷은 실제 UTC 저장 시각·판단 기준일·원자료 해시·계산기 바이트 해시와 원래 계산한 18개 행을 보존합니다. 과거 기록을 소급 생성하지 않고, 배포·거래 성공을 뜻하지 않습니다. 최초 수동 기록 두 건은 보관 자료의 실제 계산 기록입니다.
- 예약 갱신은 비교 자료 갱신 단계가 실제 성공했을 때만 스냅샷을 추가합니다. 기존 자료 검증만 통과한 실패 갱신은 새 기록을 만들지 않습니다. 원래의 실패 보존·stale-main·비강제 push 정책을 유지합니다.
- 독립형 HTML에도 기록 목록과 원본 기록 문자열을 함께 넣고 해시를 검증합니다. 저장 CSV는 필터와 관계없이 선택 기록의 전체 18개 행이며, 재계산 CSV는 선택 종목·기간의 모든 달력일을 포함합니다.

## 보존과 통합
최신 v1.27.1의 수치 경계·고정 헤더·입력·재시도·성능 수정과 최신 원자료를 보존합니다. 원자료와 기존 판정 규칙을 새 이력 규칙으로 대체하지 않습니다. BTC 첫 행, 18개 자산 순서, 제거된 상단 정보줄·하단 안내 영역을 유지합니다. PR #12, Telegram·카카오·SDK 작업은 별도입니다.

## 검증
- 최신 계산기 기준 16,762개 달력 기준일 × 18개 자산 = 301,716건에서 계산·판정·관측 수·출처가 일치합니다. 범위는 1980-12-12–2026-11-02이며, 원자료 마지막 관측 2026-10-25 이후는 지연 경계 검사이지 미래 관측·예측이 아닙니다.
- 동일 최신 원자료·기준일에서 v1.27.1 대비 기존 CSV가 바이트까지 같습니다: 18행·34필드·16,451바이트, SHA-256 `cd92bb9b88cd3881c0280c7856e0267a0a2767eaf7e424e757f16e2cfd9e5f29`.
- 로컬 전체 회귀 1,081개와 수치·연구·ETH 사건·재무 경로·시계·성능·정적·독립형 검사가 통과했습니다. 로컬 Java 부재로 TLC formal 실행은 GitHub CI·Pages의 필수 검사에서 확인하며 로컬 통과로 표시하지 않습니다. HTTP와 독립형에서 1440×1000, 390×844, 320×700, 700×600, 620×420, 800×420, 768×1024, 1024×768을 검사합니다. 이는 모든 브라우저·실기기·전체 WCAG 인증이 아닙니다.
- 빠른 닫기/재열기의 지연 close 이벤트, 저장 모드 설명, 종목 바로가기의 이전 필터·날짜, CSV 취소·원본 무결성·파일 잠금·부분 저장·재시도를 별도로 검사합니다.

## 외부 검토와 배포 증거 구분
사용자가 이번 헤더·판단 이력 변경에 한해 외부 3단계 교차검토를 생략하고 CI 후 배포하도록 명시적으로 승인했습니다. ChatGPT thesis / Gemini adversarial / ChatGPT reverse는 모두 **NOT_RUN**입니다. 외부 검토 완료나 검증된 투자 신호라고 주장하지 않습니다. 로컬 결과, GitHub CI, Pages·릴리스 및 공개 파일·화면 수락은 각각 별도로 확인합니다.
