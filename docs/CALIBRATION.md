# 예측 구간 캘리브레이션 (WP2)

구현: `dist/forecast/forecast-calibration.js` · 스크립트: `scripts/estimate-calibration.mjs` · 산출: `dist/data/forecast-calibration/factors.json`

## 절차
1. 자산·지평별 표준화잔차 `z`(무작위보행 중앙값 0, 직전 창 변동성)를 워크포워드로 수집한다.
2. **앞 70%만** 사용해 계수를 추정한다: 드리프트(`zMean`), 폭 배율(`k80`, `k50`), 첨도.
3. **뒤 30%(홀드아웃)** 에서 보정 전·후 커버리지를 비교한다. 명목 80% ±5%p 통과 여부를 기록한다.
4. 적합 표본이 200개 미만이면 **보정하지 않는다**(`calibrated:false`, 이유 기록).

## 적용 규칙
- `factors.calibrated === true` 이고 홀드아웃 판정이 통과일 때만 구간을 넓히고 중심을 옮긴다.
- 적용 시 화면 문구는 "보정된 80% 범위(실측 X%)"로만 바꾼다. 검증 전에는 "시나리오 범위 · 확률구간 아님"을 유지한다.
- 드리프트는 상승장 편향이므로 레짐 분리 전에는 옵션(기본 끔)으로 둔다.

## 남은 일
- 통과한 (자산, 지평) 조합만 골라 예측 경로·밴드에 연결하고, 화면 배지는 WP4에서 붙인다.
- 롤링 재추정 주기와 재보정 시각 기록은 데이터 갱신 파이프라인에 연결해야 한다.
