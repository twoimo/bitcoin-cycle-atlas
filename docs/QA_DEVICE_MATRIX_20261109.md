## 4. 수정 내역(릴레이)
- `dist/relay-room.js`: `\n → <br>` 일괄 변환을 `softWrap()`으로 교체. 단일 줄바꿈은 공백, 2개 이상 연속은 단락 구분(`<br><br>`)으로 유지. 본문·인용·원문 블록 모두 동일 규칙.
- `tests/relay-standalone.test.mjs`: "첫 줄\n둘째 줄\n\n새 단락" → `첫 줄입니다 둘째 줄입니다<br><br>...` 검증 추가.
- 결과: 대화 열 폭을 그대로 쓰면서(`max-width: min(720px, 100%)`) 문장 단위로 재배치. 전체 테스트 3065 pass / 0 fail, `verify:static` 931파일 ok.
