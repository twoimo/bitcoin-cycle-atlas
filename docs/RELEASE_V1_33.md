# v1.33.0 · 차트와 원장 중심 화면

차트·표·분석·리서치 전반을 먹색 바탕과 절제된 황동색 강조로 정리합니다.
화면마다 달랐던 상자·둥근 탭·강조색을 공통 규칙으로 맞추고, 값과 라벨의
크기·정렬·구분선으로 정보의 우선순위를 보여 줍니다. 새로운 소개 화면이나
홍보 문구를 추가하지 않고 기존 작업 화면의 밀도를 유지합니다.

## 화면 변경

- 차트의 상하좌우 도구, 검색, 메뉴, 설정창에 같은 표면·글자·초점 색을
  적용합니다. 현재 위치와 선택한 탭은 작은 선으로 표시합니다.
- 미국·국내 시장의 관측 차트는 남은 작업 높이를 사용합니다. ztd-charts의
  실제 `height` 속성에 측정한 높이를 전달하여 축 글자와 포인터 좌표가
  늘어나지 않도록 합니다. 출처를 펼치거나 화면이 짧아지면 기존 본문
  스크롤에서 전체 자료를 읽을 수 있습니다.
- 진단 요약은 세 축의 값과 라벨을 정렬한 열로 표시합니다. 조건 실험과
  현금흐름은 입력·결과의 구분을 선과 간격으로 표현합니다. 종목 차트의
  RSI·부동산·테마 보조 정보도 같은 문서·표 체계를 사용합니다.
- 자산 비교의 식별 열과 섹터 경계를 더 명확히 하고 숫자를 정렬합니다.
  공모주 달력은 날짜와 일정을 구분하며, 리서치 목록은 제목 아래에 종목
  정보를 배치하고 본문은 읽기 편한 글줄과 출처 목록으로 정리합니다.

공통 종목 검색, 대화상자 닫기와 초점 복귀를 유지합니다.

원본 가격·관측 자료, 판단 이력·원장, 수치 계산, 리플레이 경로·저장 상태,

## 검증

원본 테스트, Chrome 상호작용 검사, Hallmark 기존 8개·통합 10개 화면을
사용합니다. Hallmark checker·baseline·경고 판정·검사 데이터는 변경하지
않습니다. 이전 static 32개, 기존 render 10개, 통합 render 2개는 상속한
기준이며 새 소스 결과와 구분합니다. 공통 static 경고를 두 번 합산하지
않습니다. 실제 완료 결과와 캡처·배포 식별자는 이 소스의 PR·CI 기록과
`docs/editorial-redesign-2026-11-07/`의 검증 기록을 따릅니다.
