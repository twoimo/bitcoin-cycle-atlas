# v1.32.0 · 시장 분석·종목 차트 통합

미국·국내·조건 실험·현금흐름을 하나의 **시장 분석** 작업공간에 모읍니다. 삼플레·RSI, 부동산, 테마·재료는 **종목 차트** 검색에서 선택합니다. 기존 상하좌우 차트 도구는 유지하고 중앙 화면만 바뀝니다.

## 화면과 경로

- 시장 분석 기본 주소는 `/market-lab/`입니다. 국내는 `?region=kr`, 조건 실험은 `?view=scenario`, 현금흐름은 `?view=cashflow`로 연결합니다. 기존 4개 페이지 주소도 계속 작동합니다.
- 종목 차트는 `/market-lab/charts/?symbol=…`로 연결합니다. TQQQ·SOXL·233740, HYPE/USDC, 부산·서울·경기·전국 아파트 자료를 검색할 수 있습니다. 기존 RSI·housing·themes 링크를 해당 종목과 지역에 연결합니다.
- 미국·국내의 지수와 선택 시점, 종목별 차트 상태를 유지합니다. 중앙 화면에서 돌아오면 실제 배경 자산인 BTC·ETH·MSTR·BMNR의 정체성과 차트를 복원합니다.
- iframe 탐색은 부모가 소유합니다. 활성 프레임·origin·탐색 epoch를 확인하고 오래된 응답이 최근 선택을 덮어쓰지 못하게 합니다. 독립 계산기와 부동산·테마의 첫 화면에서는 불필요한 시장 진단 스냅샷을 요청하지 않습니다.

## 자산 비교와 IPO

자산 비교의 갱신·판단 이력·읽는 법·CSV를 외곽 헤더 오른쪽에 모읍니다. 원래 표의 자료와 이벤트 소유권을 유지하며 비활성 상태를 동기화하고, 대화상자를 닫으면 화면에 보이는 헤더 버튼으로 초점을 돌립니다. 섹터와 분류별 표를 선택하고 현재 표시한 행을 CSV로 내보냅니다.

비교 목록에 ETH와 HYPE를 추가합니다. 기존 BTC와 함께 디지털 자산으로 보되 각 원천·관측일·수집일·표시 통화를 유지합니다. HYPE의 기준 통화는 USDC이며, 5개 과거 연도에 미달하는 자료에 기존 매수·매도 판단을 만들어 넣지 않습니다. 과거 18개 자산의 저장 판단 이력은 다시 쓰지 않습니다.

IPO 상단의 고정 위치 겹침을 없애고 검색·분류·출처와 월 이동·건수·오늘/목록 이동을 두 줄로 정리합니다. 실제 연·월을 표시하며 원래 일정 데이터와 필터 기능을 유지합니다.

## ztd-charts 사용

`Junhan2/ztd-charts`의 실제 배포 패키지 `0.2.1`을 고정 의존성으로 사용합니다. 시장 진단의 관측 차트는 `ChartCard`와 `LineChart`, 조건 실험의 축별 기여도는 `BarChart`로 표시합니다. 직선 연결·결측 구간 분리·원래 관측 index 매핑·0 기준 signed contribution을 명시합니다. 기존 계산 표와 BTC/ETH/RSI 리플레이 수학은 유지합니다. 검토한 upstream revision과 MIT 고지는 `docs/design-system/ztd-charts.md`, `dist/vendor/ztd-charts-LICENSE.txt`를 따릅니다.

## 검증 범위

새 회귀 검사는 경로 호환, 검색과 한국어 IME 입력, 시장별 선택 보존, 탐색 소유권, 헤더 액션과 초점, 필터·CSV, 원자료와 표시 통화, 결측 처리와 차트 index를 확인합니다. 기존 수치·원장·형식·정적 산출물 검증은 유지합니다. 현재 소스의 실제 검사 결과와 배포 식별자는 해당 커밋의 CI·Pages 실행 기록을 따릅니다. 브라우저 관측이나 아직 끝나지 않은 검사를 통과한 것으로 간주하지 않습니다.

저장 스냅샷을 사용하는 GitHub Pages가 서버 수집이나 거래·주문을 실행한다고 표시하지 않습니다. ETH 예측 후보의 운영 승격·전향 보정 조건과 사용자 지시에 따른 외부 검토 제외 상태는 그대로 유지합니다.
