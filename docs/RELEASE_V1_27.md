# v1.27 · 철도 전광판형 자산 비교표

## 범위와 보존
일본 철도 출발 안내판의 검은 판넬·청록/노랑 코드·흰 숫자·가로 구분선을 기존 다크 사이트의 비교표에 적용합니다. 기존 화면의 표현만 개선하며 프로젝트 구조·데이터·계산·출시 정책은 바꾸지 않습니다. BTC 첫 행, 18개 자산 기본 순서, 과거 평균·판단 경계, CSV와 불러오기/오류/재시도 동작을 유지합니다. 제거 요청을 받은 상단 정보줄과 하단 안내 영역은 복원하지 않습니다.

## 시각 체계
- 검정 `#0b0f10`, 주 글자 `#ecf1ef`, 보조 글자 `#a5b0ac`, 구분선 `#394543`, 노랑 `#f0d36c`, 청록 `#6bd7ca`.
- 종목 코드는 기존 자산군만 표시합니다. 위험 자산은 청록, 안전 자산은 노랑, 대체자산은 흰색입니다. 수익성·우선순위·매수 신호를 추가하지 않습니다. 원래 자산군 문구와 설명창을 유지하고 종목 버튼의 접근성 설명에도 자산군·분류를 제공합니다.
- 기존 사이트 글꼴을 유지하고 코드·가격·퍼센트에 등폭 숫자를 사용합니다. 추가 폰트 요청·이미지·아이콘 패키지·깜박임·가짜 실시간 효과는 없습니다.
- 전면의 녹색/붉은 셀 배경과 채운 판단 배지를 없애 숫자가 먼저 읽히게 합니다. 등락 방향의 기존 색과 부호, 판단의 명시적 문구는 보존합니다.
- 실제 자산군 경계의 가로선과 주요 열 경계만 강조하고, 키보드 포커스에도 행을 따라 읽을 수 있습니다.

## 반응형과 설명창
- 고정 헤더·종목명과 기존 모바일 열 너비 공식을 유지합니다. 종목·판단 버튼은 모바일에서 최소 44px입니다.
- 보조 날짜의 행간과 데스크톱 행 밀도를 정돈합니다.
- 620px 이하 설명창은 긴 퍼센트가 옆 칸으로 넘치지 않도록 핵심 수치를 라벨/값 가로행으로 배치합니다. 값을 줄이거나 자르지 않습니다.
- 방법론·출처·MDD 구분·배당 제외·과거 범위 분류의 한계는 기존 읽는 법과 CSV에 유지합니다.

## 검증 계약
전체 회귀·정적·자산 수치 검사와 실제 Chromium 1440×1000, 390×844, 320×700, 700×600, 620×420, 800×420을 사용합니다. 헤더·마지막 행·가로 이동·숫자 경계·설명창 경계·선택 텍스트 대비·키보드·reduced motion·CSV를 확인합니다. 320px 설명창 경계 검사는 옛 3열 배치를 임시 복원한 음성 대조군에서 실패하는지도 확인합니다. 독립 정적 코드 검토는 이 실제 렌더링 검사와 별개입니다. 물리적 휴대전화·모든 브라우저·전체 WCAG 인증을 뜻하지 않습니다.

## 확인 결과
- 전체 Node 테스트 1,029개와 정적·독립 자산 수치·독립형 HTML 검사가 통과했습니다.
- 여섯 화면 크기의 실제 브라우저 검사와 CSV 18행·34필드가 통과했습니다.
- 1440×1000에서 18행이 처음부터 보이며, 320px 설명창의 긴 수치 겹침을 수정했습니다. 옛 3열 배치를 임시 복원하면 경계 검사가 실패하는 것을 확인했습니다.
- 검사한 본문 선택자들의 최소 문자 대비는 6.94:1입니다. 전체 접근성 인증 주장은 아닙니다.
- 데이터·계산 엔진과 기존 CSV 바이트를 보존했습니다.
- [축약된 검증 범위](rail-board-v1-27-qa.json). PR CI·Pages·공개 화면 수락은 로컬 결과와 구분해 확인합니다.

## v1.27.1 심층 공학 감사 통합

- 철도 전광판의 색·열 너비·자산군 표시·모바일 터치 영역·설명창 개선을 보존하면서, 태블릿 가로 이동 시 종목명과 제목이 어긋나는 오류를 수정했습니다.
- 시장 국면의 반복 계산을 분할상환 O(N)으로 개선하고, 가격 단위에 따라 동률 국면이 달라지는 현상과 자산표의 정확한 판단 경계 오차를 바로잡았습니다.
- 명시적 새로고침이 이전 과거 조회 실패의 대기를 해제하고, 상세 전망 기본 발행일은 최신 완료 관측 뒤로 이동합니다. 과거 기준일의 가격 검증은 미래 가격 오류에 영향을 받지 않으며 전체 행 구조·날짜 순서는 검증합니다.
- 터치 표시 작업을 frame당 최신 한 번으로 합치고, resize의 최종 좌표와 포인터 소유권을 보존합니다. 선택적 외부 글꼴 실패가 부팅을 막지 않으며 다운로드 HTML은 외부 글꼴 의존성을 제거합니다.
- 정기 갱신 자료를 잘못 거부하던 날짜 고정 테스트를 수정하고 실제 pstack 형식 모델·한국어 상태전이도·결함 주입·브라우저·성능 근거를 추가했습니다.
- [전체 감사와 검증 범위](DEEP_AUDIT_2026-10-26.md). 미래 가격 예측력이나 모든 브라우저·모든 수치 입력의 완전한 증명을 뜻하지 않습니다.
