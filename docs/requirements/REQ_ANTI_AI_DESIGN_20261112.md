# 요구사항 — AI 티 제거·브랜드 일관성 심층 점검 (초안)

작성 2026-11-12. 상태: **감사 완료·수정 대기**. 대상 `twoimo/bitcoin-cycle-atlas`의 컨퍼런스·차트 셸·대시보드.
방법: `ui-ux-pro-max` 검색(style·icons·color·ux)과 실제 브라우저 계산 스타일 감사(1440×900, 390×844)를 함께 사용했다. 수치는 2026-11-12 로컬 `dist` 실측이다.

## 1. 목적

AI가 만든 화면처럼 보이는 **템플릿 신호**를 없애고, 이 제품만의 편집·금융 리서치 톤을 유지한다. 새 장식을 더하는 작업이 아니라 **일관성·타이포·아이콘·액센트를 정리하는 작업**이다.

## 2. 감사 결과 (실측)

| 표면 | 요소 | radius≥8 | shadow | gradient | backdrop | 본문 <12px | 대문자 라벨 | UI 글리프 이모지 | 보라/비브랜드 블루 |
|---|---|---|---|---|---|---|---|---|---|
| 컨퍼런스 1440 | 142 | 1 | 0 | 0 | 0 | 8 | 0 | 1 (`☰`) | 1 (`rgb(41,98,255)` 재생 버튼) |
| 차트 셸 1440 | 806 | 1 | 0 | 0 | 0 | 216 (최소 9px) | 0 | 1 (`☰`) | 0 |
| 릴레이 1440 | 684 | 4 | 0 | 0 | 0 | 150 | 0 | 1 (`☰`) | 0 |

이미 깨끗한 항목: **그라디언트 0, 그림자 0, 필 배지 0, 대문자 eyebrow 0, 보라색 액센트 0**. 이 항목은 "없음"을 유지하는 것이 계약이며, 수정 과정에서 새로 넣지 않는다.

## 3. 발견과 수정 방향

### F1. `☰` 글리프를 아이콘으로 사용
- 증거: 컨퍼런스·차트·릴레이 헤더의 메뉴 버튼 텍스트가 `☰`(U+2630).
- 왜 AI 티인가: 폰트 글리프는 플랫폼마다 모양·굵기·정렬이 달라지고, 아이콘 시스템이 없는 화면처럼 보인다.
- 방향: SVG 아이콘(Phosphor `List` 계열)으로 교체하고, 버튼의 `aria-label`·44px 타깃·포커스 링은 유지한다.
- 수용: UI 글리프 이모지 **0**, 메뉴 버튼은 SVG + 접근성 이름, 320/1440 스크린샷.

### F2. 비브랜드 블루 재생 버튼
- 증거: `.conference-play` 배경 `rgb(41,98,255)`, `border-radius:50%`. 제품 액센트 토큰은 `--accent:#d8b56d`(골드)이다.
- 왜 AI 티인가: 골드 편집 톤 위에 Material풍 원형 블루 버튼이 얹혀 "기본 컴포넌트를 그대로 붙인" 인상을 준다.
- 방향: 한 화면 한 액센트. 재생 버튼은 골드 또는 중립 표면 + 골드 링으로 바꾸고, radius는 토큰 스케일(3~6px)로 통일한다. 크기(56px)와 히트 영역은 유지한다.
- 수용: `rgb(41,98,255)` 0건, 새 색은 `--accent`/`--surface` 토큰만, 대비 4.5:1(아이콘 3:1), 320/1440 스크린샷.

### F3. 9~11px 텍스트가 본문까지 내려옴
- 증거: 차트 216개·릴레이 150개·컨퍼런스 8개 요소가 12px 미만, 최소 9px.
- 왜 AI 티인가: 정보를 많이 넣으려고 폰트를 줄인 화면은 "생성된 대시보드" 인상을 준다. 읽기 밀도는 유지하되 위계로 해결해야 한다.
- 방향: 본문·캡션 **≥12px**, 메타데이터 **≥11px**, 차트 축 라벨만 10~11px 허용(대비 4.5:1). 줄간격 ≥1.4. 9~10px은 제거.
- 수용: 9~10px 0건, 본문 12px 미만 0건(허용 목록: 축 라벨·법적 고지), 1440/390에서 잘림·오버플로 0.

### F4. 반복되는 "재시도" 블록
- 증거: 차트·릴레이 DOM에 `재시도` 텍스트 블록이 반복적으로 존재.
- 왜 AI 티인가: 같은 상태 카드가 여러 번 렌더된 것처럼 보여 생성 템플릿의 반복으로 읽힌다.
- 방향: 실제로 동시에 보이는 중복인지 확인하고, 하나의 상태 영역으로 합친다. 숨김 상태는 DOM에서도 제거하거나 `hidden`으로 명시한다.
- 수용: 동일 화면에서 `재시도` 가시 블록 1개, 스크린리더 중복 낭독 0.

### F5. 유지해야 할 금지 패턴 (현재 0)
- 그라디언트 배경, 큰 블러 그림자, 8–20px 라운드 카드, 파스텔 카드, 필 배지, 영문 숫자 eyebrow(`01 / …`), `backdrop-filter`, 장식 이모지, 슬로건형 헤드라인.
- 수정 과정에서 위 항목이 새로 생기면 실패로 본다.

### F6. 카피 톤
- 헤드라인은 실제 데이터·기준·출처를 말한다(예: "기준: 행사 시작부터"). 추상적 슬로건·과장 금지.
- 수용: 새 카피에 수치·기준·출처 중 하나 이상이 붙는다.

## 4. 토큰 계약

| 항목 | 값 |
|---|---|
| 액센트 | `--accent: #d8b56d` 단일. 파랑·보라 신규 도입 금지 |
| 표면 | `--surface`, `--background` 기존 토큰만 |
| 라운드 | 0 / 2 / 3 / 6px 스케일. 8px 이상은 칩·아바타 예외 |
| 텍스트 | 11 / 12 / 13 / 16 / 20px. 본문 ≥12, 메타 ≥11 |

| 금지 | 그림자·그라디언트·블러·필 배지·이모지 아이콘 |

## 6. 우선순위·범위

- 우선순위: **P2a**(리브랜딩 P2b와 병행 가능). P1c-B·R16/R17보다 뒤, RAG(P3)보다 앞.
- 범위: 컨퍼런스, 차트 셸, 릴레이·대시보드 헤더. 마케팅 랜딩 신규 제작은 제외.
- 하지 말 것: 전체 재디자인, 장식 추가, 데이터 밀도 희생, 스크린샷·측정 없는 변경.

## 7. 실행

1. Pro에 1건씩 요청한다: F1(아이콘) → F2(재생 버튼) → F3(타이포) → F4(중복 상태).
2. 각 커밋마다 D-1~D-8 중 해당 항목을 수치로 보고한다.
3. 이 문서와 체크리스트 R18을 같은 커밋에서 갱신한다.
