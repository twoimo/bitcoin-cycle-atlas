## 1. 목적

AI가 만든 화면처럼 보이는 **템플릿 신호**를 없애고, 이 제품만의 편집·금융 리서치 톤을 유지한다. 새 장식을 더하는 작업이 아니라 **일관성·타이포·아이콘·액센트를 정리하는 작업**이다.

## 3. 발견과 수정 방향

### F1. `☰` 글리프를 아이콘으로 사용
- 증거: 컨퍼런스·차트·릴레이 헤더의 메뉴 버튼 텍스트가 `☰`(U+2630).
- 왜 AI 티인가: 폰트 글리프는 플랫폼마다 모양·굵기·정렬이 달라지고, 아이콘 시스템이 없는 화면처럼 보인다.
- 방향: SVG 아이콘(Phosphor `List` 계열)으로 교체하고, 버튼의 `aria-label`·44px 타깃·포커스 링은 유지한다.
- 수용: UI 글리프 이모지 **0**, 메뉴 버튼은 SVG + 접근성 이름, 320/1440 스크린샷.
- Mac 2026-11-13 12:29 KST `7d45f88`: 메뉴 글리프는 컨퍼런스·릴레이에서 0. 수용의 UI 글리프 0은 아웃룩 설정 버튼 U+2699 5개 때문에 미달. Q-P5F1-1.
- Mac 2026-11-13 12:57 KST `36869d2`: 같은 명령으로 여섯 화면 D-1 이후 0, 실패 0, exit 0. F1 글리프 수용을 닫는다. [Mac 영수증](../evidence/r19-p5-f1-gear/mac-36869d2.md).

### F2. 비브랜드 블루 재생 버튼
- 과거 증거(2026-11-12): `.conference-play` 배경 `rgb(41,98,255)`, `border-radius:50%`. 당시 문서의 액센트는 골드 `#d8b56d`였다.
- 현재 기준(`3356e68`, 2026-11-13 사용자 지시): 크기 56px, 배경 `var(--ui-primary)` → `--accent:#6c4dff`, radius `var(--pill-radius)` → 999px. 위 RGB 리터럴은 이미 `player.css`에 없다. 전역 액센트는 변경하지 않는다.
- 방향: 채워진 알약을 기존 중립 `--surface`와 기존 액센트 링으로 바꾼다. 기존 `--text` 아이콘과 `--surface-hover`를 사용하고 radius는 0/2/3/6px 스케일의 **6px**로 맞춘다. 56px·히트 영역·접근성 이름·재생 동작·2px 포커스를 유지한다.
- 수용: 계산된 배경의 `rgb(41,98,255)` 0건, hue 200–260 **신규** 0건, 새 색 리터럴 0, 텍스트 대비 4.5:1·아이콘 3:1, 320/1440 스크린샷. D-1과 기존 검사기는 그대로 둔다.
- 구현·검증: [F2 근거](../evidence/r19-p5-f2/README.md). 소스 토큰 계산과 native 측정을 구분하며, 현재 native 0/4·캡처 0/4로 수용은 열림이다.

### F3. 9~11px 텍스트가 본문까지 내려옴
- 증거: 차트 216개·릴레이 150개·컨퍼런스 8개 요소가 12px 미만, 최소 9px.
- 왜 AI 티인가: 정보를 많이 넣으려고 폰트를 줄인 화면은 "생성된 대시보드" 인상을 준다. 읽기 밀도는 유지하되 위계로 해결해야 한다.
- 방향: 본문·캡션 **≥12px**, 메타데이터 **≥11px**, 차트 축 라벨만 10~11px 허용(대비 4.5:1). 줄간격 ≥1.4. 9~10px은 제거.
- 수용: 9~10px 0건, 본문 12px 미만 0건(허용 목록: 축 라벨·법적 고지), 1440/390에서 잘림·오버플로 0.

### F4. 반복되는 "재시도" 블록
- 증거: 차트·릴레이 DOM에 `재시도` 텍스트 블록이 반복적으로 존재.
- 왜 AI 티인가: 같은 상태 카드가 여러 번 렌더된 것처럼 보여 생성 템플릿의 반복으로 읽힌다.
- 방향: 실제로 동시에 보이는 중복인지 확인하고, 하나의 상태 영역으로 합친다. 숨김 상태는 DOM에서도 제거하거나 `hidden`으로 명시한다.
- 수용: 동일 화면에서 `재시도` 가시 블록 1개, 스크린리더 중복 낭독 0.

### F5. 유지해야 할 금지 패턴 (현재 0)
