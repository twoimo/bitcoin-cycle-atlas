## 공통 원칙
- 위 세 요구 문서의 보안 최소선·수용 기준·명시적 구현 보류를 보존한다. 구현에 필요한 미결정 항목은 별도로 확정하며, 문서 정리 완료를 구현 완료로 읽지 않는다.
- 인증 도입은 릴레이·차트 등 모든 화면의 접근 게이트와 함께 설계한다(로그인 없이는 데이터 API가 응답하지 않는 구조).
- 3열 AI 채팅은 인증 체계(역할)와 연동해 노출 범위를 정한다.
- 각 항목은 구현 후 **심층 QA 5축**(기능·시각·접근성·성능·일관성)을 통과해야 완료다. QA 발견은 `Q-` 행으로 큐 맨 앞에 재투입하고, 문서에 근거·스크린샷 경로를 남긴다.
