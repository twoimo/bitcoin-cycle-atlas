# 요구사항 — 대한민국 명절·행사 시즌 테마 (자동 적용)

작성 2026-11-09. 상태: **요구사항 확정 · 구현 보류**(사용자 지시에 따라 이번에는 문서만 정리). 기준선: 다크/라이트 테마.

## 1. 목표
- 지금은 다크·라이트 두 가지뿐이다. 여기에 **날짜 기반 시즌 테마**를 더한다.
- 명절·행사 **당일 전후 창(window)** 안에서 자동 적용되고, 창을 벗어나면 자동 해제된다.
- 다크/라이트 설정은 그대로 유지된다. 시즌 테마는 **장식 레이어**이며 차트 데이터 색을 바꾸지 않는다.

## 3. 판정 규칙
1. 기준은 **KST 달력 날짜**(`YYYY-MM-DD`)다. UTC 타임스탬프는 +9시간 후 날짜로 자른다.
2. 창이 겹치면 다음 순서로 하나를 고른다.
   1. 그날이 기준일인 테마
   2. 우선순위(priority)가 높은 테마
   3. 기준일까지 거리가 가까운 테마
   4. 배열 선언 순서
3. 창이 해를 넘는 경우(연말·새해)를 위해 전년·당년·차년 창을 모두 검사한다.
4. 테마가 없으면 속성을 지운다(이전 시즌이 남지 않는다).

## 4. 음력 명절 데이터
- 설날·추석·부처님오신날은 해마다 양력 날짜가 바뀐다. 손으로 적지 않고 **생성 스크립트**로 만든다.
- `scripts/build-seasonal-calendar.mjs` → `dist/data/seasonal/lunar-calendar.json` (2024–2040).
- 변환은 MIT 라이선스 `korean-lunar-calendar`(devDependency)를 쓴다. **런타임 의존성 없음**(JSON만 배포).
- 재생성 시점: 표 범위가 끝나기 전(2040년 이전) 또는 규칙 변경 시. 검증은 6절 전수 점검이 한다.
- 표 범위를 벗어나면 음력 테마만 빠지고 양력 테마는 정상 동작한다(테스트로 고정).

## 5. 적용 방식과 안전 경계
- 대상은 `<html>`의 `data-season`, `data-season-phase`, `data-season-label` 세 속성이다.
- **차트 데이터 색은 바꾸지 않는다.** `--accent`, `--green`, `--red` 등 데이터 의미가 있는 토큰은 그대로 두고, `--season-*` 장식 토큰만 덮어쓴다.
- 장식 범위: 상단 2px 머리선, 명절 당일 상단 프레임 틴트와 옅은 글로우, 사이드바 활성 항목 틴트, 브랜드 아이콘 링, 포커스 링.
- 사용자 제어: `localStorage.atlas-season-mode` = `auto`(기본) | `off` | 특정 테마 id. 오른쪽 아래 시즌 배지를 누르면 즉시 꺼진다.
- 접근성: `prefers-reduced-motion`이면 호흡 애니메이션을 끄고, `forced-colors`·인쇄에서는 장식을 전부 제거한다.
- 성능: 첫 페인트 뒤 `requestAnimationFrame`에서 적용, 음력 표는 1회 캐시, 30분 간격·탭 복귀 시 재판정.

## 6. QA 계획 (구현 시 검증 방법)
### 달력 전수 점검
- 스크립트로 **2024–2040 17년 × 365/366일**을 전수 계산해 아래를 확인한다.
  - 각 날짜에 적용된 테마가 **정확히 0 또는 1개**
  - 적용된 테마의 창(기준일 ± before/after) 안에 있는지
  - 연도별 커버리지 비율과 사용된 테마 수 집계(예상: 연 35~40%, 17~18종)
  - 위반 건수 0이 아니면 배포 차단

### 단위 테스트
- 18개 테마가 각자의 기준일에 자기 id로 해석되는지
- 음력 명절 교차 검증: 2024·2025·2026·2027·2030·2035년의 설날·추석·부처님오신날 날짜
- 창 경계: 시작 전날(없음) → 첫날 → 기준일 → 마지막 날 → 다음 날(없음)
- 해를 넘는 창: 12/31 연말 → 1/1 새해 → 1/6 마지막 → 1/7 없음
- 겹침 우선순위: 5/5 어린이날, 5/6 어버이날, 11/12 수능, 12/27 연말, 2/15 설날
- 음력 표 범위 밖(예: 2045)에서 음력만 빠지고 양력 테마는 동작
- 창 밖 날짜에서 속성이 남지 않는지(이전 시즌 잔상 금지)
- KST 변환: UTC 16:00Z = 다음 날

### 브라우저 검증
- 18개 테마를 강제 적용해 시즌 색·속성이 모두 다른지, **차트 시리즈 색(`--accent`)이 변하지 않는지**
- `off` → 속성 제거, `auto` 복귀 시 오늘 테마 재적용, 새로고침 후 설정 유지
- 시즌 배지 표시·문구·클릭 해제
- 6개 뷰포트(390·320·768·1024·1440·1920)에서 배지가 차트·하단 내비를 가리지 않는지
- `prefers-reduced-motion`(애니메이션 꺼짐), `forced-colors`, 인쇄에서 장식 제거

## 7. 수용 기준
1. 18개 이벤트가 각자의 창 안에서 자동 적용되고, 창을 벗어나면 해제된다.
2. 음력 명절이 표에 따라 정확한 날짜에 적용된다(교차 검증 8개 연도).
3. 6,209일 전수 점검에서 위반 0.
4. 다크/라이트 전환과 독립적으로 동작한다(동시 적용 시 시즌 장식만 얹힘).
5. 차트 시리즈 색·범례 색이 시즌에 의해 바뀌지 않는다.
6. 사용자가 배지 한 번으로 끌 수 있고, 끈 상태가 새로고침 후에도 유지된다.
7. 모션 최소화·강제 대비·인쇄에서 장식이 사라진다.
