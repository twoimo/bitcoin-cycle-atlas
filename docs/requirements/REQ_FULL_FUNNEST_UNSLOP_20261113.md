# 전면 UI/UX 개선과 실제 Funnest 차트 교체

## 최신 사용자 범위

2026-11-13 사용자가 UI/UX Pro Max와 Unslop을 명시하고 전체 프로젝트의 디자인·레이아웃·스타일·UI/UX 심층 QA/개선, 코인·주식·부동산 차트의 funnest-xyz/funnest-charts 완전 교체, 병렬 착수를 요청했다. 이는 이전의 차트 크롬만 교체하고 기존 가격 엔진을 유지하는 P2 하이브리드 범위와 UIUX/clone만 사용하던 도구 선택을 대체한다. 병합·배포·유료 인프라 허용으로 확대하지 않는다.

## 방향 다섯 줄

- 제품: 한국어 사용자가 실제 출처에 기반해 여러 자산의 시계열과 가설을 비교하는 리서치 작업대.
- 성격: 정확함, 절제, 탐색의 명료함.
- 환경: 금융 리서치 데스크와 관측 장비. 배경은 흑연색 중성 톤, 정보가 색을 갖는다.
- 주목점: 실제 데이터 차트와 원문 자료. 장식 이미지나 가짜 KPI는 넣지 않는다.
- 고유 표현: 데이터의 기준 시각·출처·관측/예측 상태를 일관되게 구분한다.

기존 차트 직행, 다크 기본값과 저장된 테마 선택, 한국어 폰트, 단일 상단 도구 행, 좁은 우측 레일과 독립 스크롤을 유지한다. 4px 간격 체계·정보 그룹간 위계·숫자 열 정렬을 적용하고 과한 pill/광택/그라디언트/큰 그림자를 제거한다. 원문의 이모지·문장과 실제 의미 색상은 보존한다. Unslop의 일반적인 넓은 사이드바·카드 radius/hero 수치는 금융 작업대의 실제 제약과 사용자의 절제된 스타일을 대체하지 않는다.

UIUX 전체 검색이 제안한 enterprise gateway/판매 CTA/hero/glow는 제품에 맞지 않아 기각했다. 재검색의 검증된 data-dense-dashboard 권고 중 정보 밀도와 읽기/키보드/대비 원칙만 채택한다. 새 템플릿을 덮어씌우지 않는다.

## 병렬 소유권

A: 실제 Funnest 패키지·공통 런타임·네이티브 차트 JS·의존성/빌드 연결.
B: React 시장/주식/부동산 및 보조 차트의 실제 렌더러와 좁은 데이터 어댑터.
C: 작성된 dist 공통/비차트 CSS.
D: apps/web CSS.
부모: 요구사항·데이터 보존·전 경로 QA·필요한 독립 의미/상호작용 수정·생성물·통합 Git. 각 작업은 격리 워크트리, 상충 파일은 단일 작성자.

## 전면 교체 판정

- 실제 Funnest가 가격/캔들/시계열/산점도를 그려야 한다. 숨긴 옛 가격 경로나 dataset 표식만으로 도입을 주장하지 않는다.
- 공통 차트 4종(BTCUSD/ETHUSD/MSTR/BMNR)과 호스팅 차트 8종(TQQQ/SOXL/233740/HYPE/부동산4지역), 그 하위 비교·지표·예측·리플레이·시장 보조 시각화를 목록으로 대조한다.
- 원본에 없는 OHLC/거래량/월/날짜/가격을 만들지 않는다. 월별 종가/지수는 line으로, 결측은 결측으로 유지한다.
- 예측·관측 분리, 밴드/extrema, 로그/% 축, 원본 시각·단위, 사건/출처, 범위 저장·복원, as-of 고정 예측과 rewind, 키보드·포인터·터치, resize/suspend/destroy 계약을 보존한다.
- Atlas 전용 주석/예측 레이어를 Funnest 좌표에 연결하는 확장은 허용한다. 기존 가격 엔진을 계속 활성 경로로 쓰는 부분은 미교체로 센다.
- 라이선스/NOTICE와 정확한 버전·출처·번들 정체성을 남기고, 추가 의존성 설치 스크립트는 실행하지 않는다.

## 수용 및 제한

13개 정본 페이지와 경로 별 별칭, 12개 차트 종목, 별도 standalone/embedded 진입을 전수 목록으로 유지한다. 320/390/768/1440 및 짧은 가로 화면에서 dark/light, 로딩/빈 상태/오류/복구/데이터 상태, 메뉴·검색·모달·리더·표를 확인한다. 기계적 검사를 시각·스크린리더 사람 검수로 대체하지 않는다.

기존 기능/수치/불변 기록/형식 검증을 유지한다. 렌더러가 바뀐 DOM 전용 검사는 실제 새 엔진의 동등한 수치·좌표·입력·페인트 증거로 교체해야 하며, 기준을 낮추거나 보이지 않는 옛 DOM으로 통과시키지 않는다. 기존 44px 터치·2px 포커스·4.5/3.0 대비·최소 글자·가로 넘침0·A-9 2500ms/150ms 예산은 유지한다. 기능·시각·접근성·성능·일관성 5축을 별도 보고한다.
