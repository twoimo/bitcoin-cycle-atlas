# 단일 상단 도구 모음과 숨김 스크롤바

> 기록 보관 · 2026-11-07(Asia/Seoul): Hallmark는 사용자의 최신 지시로 종료됐다. 아래 계획·검증 범위·판정은 해당 과거 소스의 기록이며 현재 실행 지시나 릴리스 조건이 아니다. 현재 디자인 기준은 저장소의 `AGENTS.md`, `design.md`와 디자인 마스터를 따른다. 원본 결과와 수치는 당시 사실로 보존한다.

사용자 첨부 화면의 두 번째 영역인 기존 `.atlas-canvas-heading`에 통합 화면의 도구를 모은다. 검토일은 2026-11-07 KST다.

## 변경

- 시장 분석의 미국·한국·조건 실험·현금흐름 탭과 해당 조작을 기존 외곽 상단으로 이동한다.
- RSI·부동산·테마 차트는 외곽 종목 검색을 공유한다. 부동산의 지역·탭·요약, 테마와 RSI의 관측 정보도 같은 도구 모음에서 연다.
- 자세한 설정·기간·판단·출처는 상단 버튼의 native dialog에서 제공한다. 입력 값과 실제 계산·차트의 소유권은 원래 패널에 유지한다.
- 자산 비교의 검색·섹터·상태와 갱신·판단 이력·읽는 법·CSV를 상단으로 모으고, 추가 필터와 열 구성은 상세 메뉴로 연다.
- 공모주의 월 이동·검색·상태·달력 도구·출처, 리서치의 검색·필터·페이지 이동도 동일한 상단에 배치한다.
- 전역 및 iframe 내부에서 스크롤바의 표시를 숨긴다. 표·차트·메뉴의 원래 스크롤 소유권과 native 휠·터치·키보드 동작은 유지한다.
- 반복 방문 시 부모 toolbar mount를 재사용한다. 배경 차트의 비활성화 대상에서 해당 mount와 자손을 제외하고, 이전 문서·epoch의 입력을 차단한다.
- 종목 검색은 결과 목록만 스크롤해 현재 선택 종목이 아래쪽에 있어도 검색창과 닫기 버튼이 가려지지 않는다. 실제 child 문서에 초점이 들어가면 외곽 프레임에도 focus ring을 표시하고, 화면 전환이나 초점 이탈 시 해제한다.
- 공모주 출처 메뉴는 수집된 출처 설명과 원문 URL을 그대로 제공한다. URL의 HTTP/HTTPS scheme을 임의로 바꾸지 않는다.

## 보존 범위

이 작업 당시 저장된 시세, 기존 18개 자산 기록, ETH/HYPE 추가 데이터, 모델·수식·가격 정의, 예측 원장, ztd 차트 데이터 및 원본 Hallmark checker를 보존했다. 버전은 1.32.1이며, iframe 진입 URL까지 버전 키를 전달해 이전 entry HTML의 캐시 재사용을 방지한다.

## 검증 계약

기존 패널 검사 91개, legacy toolbar 및 관련 기존 검사 75개, Hallmark 범위 검사 16개가 로컬에서 통과했다. 생성된 Pages 산출물과 정적 참조도 검증한다. 원본 Node 24.22.2 수치·모델 gate는 CI에서 그대로 실행한다.

Native browser 검사는 320·390·1440px의 통합 화면을 실제 입력으로 확인한다. 하나의 상단 행, 중복 내부 도구 행 제거, 숨김 스크롤바, 설정·지역·종목 변경, 메뉴 초점 복귀, 자산 비교 필터와 공모주 출처 접근을 검증한다. 기존 전체 브라우저 범위에 320px 케이스 하나를 더한다.

모델 평가와 전체 Chrome 검사를 한 job에서 연속 실행한 후보는 35분 제한으로 중단됐다. 완료된 50개 케이스는 통과했지만 전체 53개 receipt가 없으므로 전체 통과로 취급하지 않는다. 두 독립 검사를 별도 runner에서 병렬 실행하고 마지막 `evaluate` job에서 동일한 소스·실행의 정확한 artifact ID와 파일 해시를 대조한다. 기존 검사 명령·판정·케이스 순서와 worker별 35분 한도는 유지하며, 전체 완료·소스 무결성·원래 증거 패킷 생성이 모두 성공해야 최종 통과한다. 재시도 artifact는 앞선 기록을 덮어쓰지 않는다.

당시 Hallmark 검증 계약은 기존 8개 URL과 별도 통합 화면 10개 URL의 변경 전·후 검사였다. 실제 부모 toolbar와 child chart/표가 모두 준비된 화면을 대상으로 했고 누락·예외·timeout·FAIL·REFLEX는 성공으로 처리하지 않았다. 당시 38 WARN의 원문과 범위 한계는 [hallmark-triage.md](hallmark-triage.md)에 보존돼 있다.

이 문서의 검사 계약은 최종 CI·렌더링·배포 성공을 뜻하지 않는다. 해당 결과와 정확한 commit, 실행 URL 및 공개 배포 확인은 이 변경의 PR에 기록한다.
