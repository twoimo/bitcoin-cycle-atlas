## 구현

### 기존 조작 영역 위에 표시하는 형제 노드

`dist/ui/page-description.js`는 기존 h1과 설명 노드를 그대로 사용한다. `.atlas-page-intro`는 계속 `.atlas-canvas-heading` 바로 다음 형제이며, 툴바 내부로 이동하지 않는다. 이 구조가 linkedom의 기존 DOM 소유권·listener 보존 검사와 맞는다.

- 가격 차트에서는 기존 종목 선택 버튼의 윗부분에 `가격 차트`를 표시한다. 같은 버튼의 아래쪽은 기존 종목명·아이콘이 사용한다.
- compare에서는 기존 툴바의 왼쪽에 제목용 가로 공간 76px을 확보하고 그 안에 `사이클 비교`를 표시한다. 컨트롤은 기존 가로 스크롤 영역을 계속 사용한다.
- 제목 wrapper는 `position:fixed`여서 새 레이아웃 행을 만들지 않는다. 툴바·도크·플롯의 높이를 변경하지 않는다.
- 넓은 화면의 fine/none 포인터에서는 종목 버튼을 36px로 만든다. 기존 38px 툴바 안에 두 줄이 들어간다. coarse 포인터의 기존 44px 목표 크기는 유지한다.
- h1의 `aria-describedby="atlas-page-description"` 연결을 유지한다. 설명만 시각적으로 숨기며 h1 자체는 보인다.
- `ResizeObserver`, resize, 캡처 단계 scroll이 실제 anchor 좌표를 따라간다. 늦은 툴바 생성·교체와 종목 버튼 교체도 추적한다. destroy에서 observer·listener·예약 프레임을 정리한다.
- h1은 pointer event를 받지 않아 기존 종목 버튼의 클릭을 가로채지 않는다. 가로 스크롤 때는 툴바 경계로 잘라 레일 위에 그려지지 않게 한다. 열린 사이클 메뉴가 올리는 툴바 z-index도 고려했다.

### 문서의 h1 소유권

shell을 유일한 h1 소유자로 유지하도록 숨은 전망 제목·자산표 제목·리서치 리더 제목·릴레이 기사 제목을 h2로 바꿨다. 제목 전용 CSS와 리서치 제목 포커스 선택자도 함께 맞췄다. 기존 ID·aria 연결·표시 문구는 유지했다. legacy `#chart-heading`의 잘못된 닫는 태그도 수정했다.

같은 일반 사용자 권한 조건으로 **전체 단위 테스트를 다시 실행해 3,375/3,375 통과·실패 0·skip 0**을 확인했다(632.48초).
