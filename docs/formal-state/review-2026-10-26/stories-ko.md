# 과거 캔들 재시도와 요청 소유권 점검

점검 기준은 `1b7c87ce4fe5d44d05560320bb3a270c639e3bbf`의 실제 코드다. 이전 PR #12에 준비된 재시도 수정안을 현재의 BTC·ETH 공통 컨트롤러에 맞춰 적용하고 다시 검증했다. 이전 보고서의 통과 결과를 이번 검증으로 간주하지 않았다.

시장 컨트롤러의 최종 대응 검토와 재실행 기준은 게시된 제품 커밋 `c8f9d985a7a99cdee13a5c74eeda37168f1c7ea8`이다. 이 커밋은 갱신된 main `65182efcb9a833b2be091c552a0291d47d50b32c`를 포함한다. 컨트롤러의 SHA-256은 `092b77e78d3f430205c2da45d37395ac3f59606391a48f1c07a4f43ee71cb83a`로 앞서 재현·수정한 소스와 같았다. 해당 게시 커밋에서 형식 모델, 32개 실제 코드 사례, 두 변이와 복원 검사를 다시 실행한 후 동기화 기록을 갱신했다.

## 1. 실제로 재현한 오류: 새로고침이 과거 봉 재시도를 막는다

**규칙:** 사용자가 새로고침을 실행하고 그 요청이 끝나면, 이전 과거 조회 실패의 대기 시간이 같은 화면의 재조회를 막으면 안 된다.

1. 아직 불러오지 않은 과거 기간으로 이동한다.
2. 과거 봉 요청이 HTTP 503으로 실패해 30초 재시도 대기가 생긴다.
3. 대기가 끝나기 전에 새로고침을 선택한다.
4. 최근 봉 요청도 HTTP 503으로 실패한다. 기존 캔들은 유지된다.
5. 같은 과거 기간을 다시 요청한다. 수정 전에는 HTTP 요청이 두 번에서 멈추고 과거 봉을 받지 못한다. 수정 후에는 세 번째 요청이 실행되어 그 기간의 실제 캔들을 받는다.

`tests/intraday-history.test.mjs`는 실제 `load`·`ensureRange`·`get` 공개 함수와 실제 응답 파서를 호출한다. BTC-USD와 ETH-USD 두 경우 모두 수정 전 `2 !== 3`으로 실패했고, 수정 후 통과했다. 일반적인 화면 이동은 실패 대기를 그대로 지킨다. 새로고침만 이전 실패의 대기를 해제하며 요청 간 속도 제한은 유지한다.

[간단한 전후 그림](comparison.png)의 빨강은 수정 전 실패, 초록은 수정 후 가능해진 재시도다. [pstack 반례 그림](history-retry/bug-1.png)은 도구의 색 규칙에 따라 **수정으로 차단한 과거 오류를 초록으로 표시**한다. 두 그림의 색이 뜻하는 대상이 다르다. 간단한 전후 그림은 검증된 경로를 설명하는 도식이며 별도 수학 증명은 아니다.

TLC의 수정 전 첫 반례 검사에서는 서로 다른 상태 13개를 찾은 시점에 `RefreshCanRetry`가 깨졌다. pstack이 설명 그림을 위해 전체 그래프를 생성하면 수정 전 상태는 18개, 전이는 40개다. 수정 후 모델은 15개 상태를 모두 조사하고 `TypeOK`와 `RefreshCanRetry`를 통과했다. 수치는 각각 `market-verification.json`, `history-retry/summary.json`, `fixed-summary.json`에서 읽었다. 첫 반례의 부분 탐색 수를 전체 탐색 수로 혼동하면 안 된다.

재시도 결함은 과거 조회 기능을 추가한 `8e0dedac78f1d8d34a82b9310ecbb161bad1f9cc`의 `load`·`ensureRange`에도 존재한다. 이번에는 오래된 브랜치를 통째로 병합하지 않고 그 수정 의도를 현재 제품별 캐시와 요청 소유권을 보존하면서 적용했다.

## 2. 기존 방어가 유지되는지 확인: 취소된 응답이 새 차트를 덮지 않는다

**규칙:** 취소되거나 더 새 요청으로 교체된 작업은 현재 차트에 결과나 알림을 게시하면 안 된다.

1. 차트를 열었는데 거래소 요청이 실패하여 저장 자료를 기다린다.
2. 저장 자료가 도착하기 전에 다른 기간을 고르거나 새로고침한다.
3. 과거 요청의 저장 자료가 늦게 도착한다.
4. 현재 코드는 그 결과를 무시한다. 실제 코드의 저장 자료 소유권 검사 한 줄을 임시 사본에서 제거하면 오래된 응답이 덮어쓰는 회귀 검사가 실패한다.

이는 **현재 제품에서 새 경쟁 오류를 발견했다는 뜻이 아니다**. 기존 방어가 효과가 있고 검사도 그 방어가 사라진 것을 잡아내는지 확인한 음성 대조군이다. 현재 소유권 모델은 최대 요청 세대 3개, 대표 기간 2개 범위에서 서로 다른 상태 2,081개를 모두 조사했다.

## 3. 검증 도구와 코드의 대응

기존 시장 상태차트 매핑은 이전 pstack의 배열 해석에 맞춰 `phase[active - 1]`을 읽었다. 이번 upstream pstack은 TLA 튜플을 1부터 읽도록 정하고, 0번 접근을 실행 오류로 막는다. 실제 실행에서 이를 확인한 뒤 매핑을 `phase[active]`로 고쳤다. 이는 상태차트 도구와의 호환성 수정이며 제품 상태 전이의 변경은 아니다. 모델의 행동 조건에는 현재 코드 경로·줄을 붙였다. 비교 그림의 `summary.json`에는 출처가 없는 조건이 남아 있지 않다.

기존 ETH와 MSTR·BMNR 모델도 독립적으로 다시 실행했다. ETH는 2,243개 상태, 초기화 재현 17개, 실제 코드 변이 9개를 검사했다. 주식 화면은 46,252개 상태, 초기화 재현 28개, 코드 변이 7개를 검사했다. 현재 모델과 원본·복원 코드는 통과했고 의도적으로 깨뜨린 변이는 예상한 규칙 또는 단언에서 실패했다. 이 화면들의 상태를 바꾸는 코드와 부팅 신호는 이전 대응 검토 이후 변경되지 않았다.

최초 `1b7c87c` 기준 결과는 `*-baseline.json`에 그대로 보존했다. 최종 제품 커밋에서는 import 버전과 선택적 글꼴 오류의 부팅 처리가 바뀌었으므로, 게시된 `c8f9d985a7a99cdee13a5c74eeda37168f1c7ea8`에서 기존 ETH·주식 검증 명령도 각각 다시 실행했다. 범위나 불변식은 늘리거나 완화하지 않았다.

- [최종 ETH 영수증](eth-final.json): 서로 다른 상태 **2,243개**, 원본 초기화 재현 **17개 통과**, 실제 코드 변이 **9개** 예상 실패, 복원 후 **17개 다시 통과**. 소스 SHA-256은 `54242617702e74894fdadd9edd67e678e3617e6f65a37d8ed3a929b5fc94687c`다.
- [최종 MSTR·BMNR 영수증](equity-final.json): 서로 다른 상태 **46,252개**, 원본 초기화 재현 **28개 통과**, 실제 코드 변이 **7개** 예상 실패, 복원 후 **28개 다시 통과**. 소스 SHA-256은 `c3d6422da4b59dafbd54f878def9a6c8d027cc8952eb28dcacf4114bb4ef7623`다.

두 재현 검사 모두 최종 제품의 초기화 함수와 부팅 스크립트를 실행했다. DOM·그리기·HTTP·스케줄링 경계는 검사 도구가 주입한다. 실제 글꼴 다운로드, 브라우저 픽셀, 태블릿의 실제 입력 동작까지 형식 검증했다는 뜻은 아니다. 최종 `dist/index.html`의 SHA-256 `e52556b292df0073959406915c8a6e1d7f2b668d8e8ee72c67bdfa0afc0a2c05`와 각 실행 파일의 신원은 `chart-manifest.json`에도 기록했다.

## 재실행과 한계

저장소 최상위에서 다음 명령을 실행한다.

```sh
node scripts/verify-market-state.mjs /tmp/market-verification.json
```

이 명령은 TLC 1.7.4를 SHA-256으로 고정하고 현재·결함 모델을 각각 검사한다. 실제 코드 32개 사례가 실행되었는지 TAP 집계로 확인하고, 두 변이를 별개 임시 사본에 적용한다. 임시 사본을 복원한 뒤 32개 사례가 다시 모두 통과해야 완료된다. 건너뜀·취소·도구 실행 실패를 통과로 세지 않는다.

재시도 모델은 검증된 캔들과 미조회 화면이 있는 단일 기간의 유한 추상화다. 재시도 시각을 참·거짓 대기 상태로 나타내며 실제 30초, 시계 이동, 여러 페이지의 값, 제품 간 상호작용이나 무한한 요청 수를 증명하지 않는다. 요청 소유권 모델과 재시도 모델을 따로 검사했으며 두 모델을 합친 전체 프로그램 증명도 아니다. 가격 예측력·경제 모델의 타당성·브라우저 화면·입력 지연·결국 요청이 끝난다는 성질은 이 검사 범위 밖이다.

`fixed.png`는 통과한 모델의 가장 짧은 경로만 표시한 요약 그림이다. 생략된 8개 전이는 `fixed-summary.json`의 `cover.leftOutTransitions`에 있다. 모든 경로를 그린 척하지 않는다. PNG 7개를 실제로 열어 확인했고, 한국어 글꼴의 측정 오차를 교정해 글자 넘침을 없앴다.
