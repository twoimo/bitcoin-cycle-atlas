## 계산

앱 기본 가정은 과거36개월 평균, 중립±10%, 평가시차2개월이다. 강연에서 확정한 평균 기준으로 제시하지 않는다. 선택 가능한 평균12/36/60개월, 중립0/5/10/20%, 시차0/1/2/3개월이다.

- 평균은 신호월을 제외한 직전W개의 연속된 달만 사용한다. 결측은 보간하거나0으로 치환하지 않는다. 경계값은 중립이다.
- 가설1: 원수준 상관, 거래량전월비/가격전월비 상관, 평균편차/가격전월비 상관을 분리한다. ±6개월 시차는 별도 표다. 추세 때문에 수준 상관을 예측력으로 해석하지 않는다. 화면의 |r|0.2 구분은 편의상 표기이며 유의성 검정이 아니다.
- 가설2·3: 신호월t의 상태로 분류하고 `100*(I[t+lag+h]/I[t+lag]-1)`을 계산한다. h=1/3/6/12개월. 가격 동일은 보합이다. 중간 결측이나 분석 종료 이후의 결과는 제외한다. 기본 빈도는 동일한 평가 가능 월 전체의 상승/하락 비율이다.
- 2021년 이후는 고정 최근 구간이며 외부 검증으로 사전 등록된 holdout이 아니다. 비중첩 결과는 첫 평가 가능 월을 기준으로h개월 간격의 고정 표본이다. 표본이 작으면 결과가 크게 달라질 수 있다.
- 최신 수정자료로 한 회고 분석이다. 당시 공표시각·빈티지·과거 실시간 가용 자료를 복원하지 않았고 시차2개월만으로 이를 보장하지 않는다. 실제 매매성과·비용·세금·자산선택·인과성·금리/정책/계절성 통제는 검증하지 않았다.

기본조건의 부산3개월 상승 빈도75/87(86.2%), 하락 빈도59/96(61.5%). 그러나2021년 이후 상회→상승은10/19(52.6%)로 낮다. 서울의 하회→하락33/92(35.9%), 전국33/79(41.8%). ‘평균 하회면 반드시 조정’이라는 보편 법칙을 지지한다고 쓰지 않는다. 자세한 모든 지역·기간 결과는 `build/housing-research/default-results.json`에 있다.

## 실행과 복구

프로젝트의 고정 Node24.22.2를 PATH 앞에 둔다. 아래 importer는 네트워크 없이 원응답의 SHA를 확인해 동일한 스냅샷을 재현한다.

```sh
node --import tsx scripts/import-housing.mts
node --import tsx apps/jobs/src/housing.ts migrate
node --import tsx apps/jobs/src/housing.ts import dist/data/housing.json
```

DB 작업에는 기존 `DATABASE_URL`이 필요하다. `migrate`는002_housing 체크섬을 확인하며 기존001과 독립적으로 실행한다. `housing_revisions`와 `housing_publications`는 기존 market-lab과 별도 channel이다. 원문 SHA, 생성시각 충돌, 역행 publication을 검사한다. 기존 판본은 revision으로 조회할 수 있고 이전 판본의 재import로 현행을 역행시키지 않는다.

`GET /api/v1/housing[?revision=...]`, `POST /api/v1/housing/analysis`가 DB 자료와 공통 계산을 제공한다. React는 동일 판본의 API/로컬 결과를 대조한다. 조회 실패 시 검증한 `/data/housing.json` 저장본을 표시한다. 원천/저장본 모두 실패하면 오류·재시도를 표시하고 이전 관측이 있으면 유지한다. 새로고침은 현재 DB 판본을 다시 읽는 동작이다.

## 검증과 다음 작업

`scripts/verify-housing.mts`와 `scripts/verify-housing-independent.py`로192조건의1,284,288필드를 다른 언어·달력기반 구현과 대조했다. 신호·평가달·분모·보합·평균·중앙값·기본빈도·상관·최근구간·비중첩 결과를 포함한다. 타입/빌드, UI37, 실제PostgreSQL/API13, 기존전체2404검사가 통과했다. 기존시장판본전체와17모형파일SHA는변경없다. 실제 IAB 검증과 원래 checker finding은 `verification.json`을 따른다.

우선 후속은 계약월 거래량 확보·해제거래 처리로 통계 시점을 맞추고, 월별 공표판본·가용시각을 축적하는 것이다. 그 다음 계절성/금리 통제와 사전에 고정한 전진 평가를 추가한다. 현재 임계값 중 좋은 결과를 사후 선택해 정확도나 투자성과를 주장하지 않는다. 기존 외부 검토·공개발행·운영배포 holds는 유지한다.
