# v1.37.1 · 계정 요청과 차트 채팅

Google 가입이 설정된 경우 ID 토큰은 주소 쿼리가 아니라 tokeninfo 본문으로 보낸다.
리다이렉트, 쿠키, Referer는 붙이지 않으며, 발급자와 이 앱의 client id가 맞을 때만 계정으로 받는다.
공개 페이지는 같은 출처에서만 프레임으로 연다. 차트 우측의 채팅은 선택 데이터와 같은 열을 쓰고,
종목 검색은 기존 종목과 출처를 유지한 채 한 줄 목록으로 고른다. 국내 진단 항목은 탐색에서 빼고,
예전 `region=kr` 주소는 미국 진단으로 연다.

# v1.37.0 · 브라우저 계정

현재 가격 차트와 릴레이를 유지한 채, 상단 오른쪽에 이 브라우저 안에서만
동작하는 계정을 둔다. 서버 세션, Google 로그인, 사이트 잠금은 만들지 않는다.
정적 자료는 로그인 없이도 그대로 읽힌다.

## 계정

- 로그인하지 않은 상단 조작은 계정 하나다. 로그인, 가입, 비밀번호 변경,
  로그아웃, 회원탈퇴를 그 대화상자에서 처리한다.
- 로그인한 뒤에는 이름의 첫 글자를 원형으로 표시하고, 누르면 프로필이 열린다.
  좁은 화면에서는 원형 조작만 상단 오른쪽에 남긴다.
- 비밀번호는 이 브라우저의 PBKDF2-SHA-256으로만 저장한다. 원문은 저장하지 않는다.
- 마지막 관리자를 지우거나 일반 회원으로 내리면 거절한다. 마지막 관리자가
  스스로 탈퇴하면 남은 활성 회원 중 가장 먼저 만든 계정이 관리자가 된다.
  활성 회원이 없으면 가장 먼저 승인 대기 중인 계정을 관리자로 켠다.

## 관리자

- 관리자 프로필의 사용자는 다른 계정을 만들고, 보고, 고치고, 탈퇴시킨다.
- 다른 계정의 비밀번호를 바꾸면 그 계정의 로그인만 끊긴다. 관리자 자신의
  비밀번호는 프로필의 비밀번호 변경에서만 바꾼다.
- 초대 코드 발급과 가입 승인·거절도 같은 사용자 창에서 한다.

## 검증

계정 저장이 겹칠 때의 탈퇴 유지, 로그아웃 실패 시 세션 유지, 마지막 관리자
승계를 단위 검사로 확인한다. 가격, 릴레이 원문, 관측 시각은 이 변경에서
다시 계산하거나 이름을 바꾸지 않는다.
