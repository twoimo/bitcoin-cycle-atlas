# v1.36.1 · 선택 종목의 조작과 주소 보존

이미 병합된 v1.36의 12개 대상 통합 차트와 TradingView 기준의 공통
외곽 구조를 유지한다. 이번 변경은 실제 공개 호스트에서 재현한 종목
소유권 오류와, 후속 운영 배포를 중단시킨 브라우저 검증 실패를 다룬다.

## 종목 전환과 직접 링크

- ETH·MSTR·BMNR에서 다른 종목으로 전환하면 원본 종목 전용 버튼을
  숨기고 비활성화한다. 공유 차트의 상태 응답이 이를 다시 활성화하지
  않으며, 원래 종목으로 돌아오면 기존 노드·이벤트·숨김 상태를 복원한다.
- 다른 종목의 차트에서 원본 ETH 데이터 설명이나 새로고침을 실행하는
  오류를 방지한다. 가격·수치 계산과 자산별 자료 소유자는 유지한다.
- 종목·지역 주소는 활성 화면이 소유한다. 숨겨진 BTC 렌더링이 ETF·HYPE·
  부동산의 직접 진입 주소에 BTC 지표 설정을 덧붙이지 않도록 한다.
- 하단 자료 상태는 마지막으로 확인된 수집 기록을 설명한다. 실제로
  활성화되지 않은 6시간 정기 실행이나 폐기된 GitHub Actions 일정을
  운영 중인 것처럼 안내하지 않는다.

## 작은 화면과 검증

- 짧은 화면에서 리플레이의 44px 터치 조작을 유지하면서 조작부의
  여백을 줄인다. 기존 가격 영역·범례·축 분리 조건은 유지한다.
- 320px 키보드 검사 전 차트에 초점을 주는 실제 포인터 입력은 연구
  자료·주석 버튼을 피하는 SVG 표면을 검증한 뒤 실행한다.
- 통합 시장 화면의 갱신 검증은 실제 BTC 부모 문서와 그 요청을
  연결한다. 정확한 URL, frame/loader, 실패 알림, 보존 가격·관측일
  검사는 그대로 적용한다. 기존 53개 브라우저 케이스를 삭제하지 않는다.
- 공개 HTTPS 호스트의 후속 진단을 12개 대상 × 1440×900·390×844·390×430,
  총 36개 독립 브라우저 컨텍스트로 확장한다. 표시 가격 차트 하나,
  종목·지역 주소, 도구와 축 배치, 대표 실제 확대·축소와 종목 복원을
  확인한다. 정확한 소스와 manifest가 일치해야 실행할 수 있다.

## 배포 증거

시작 시 GitHub main은 `69c16ad`였지만 운영 manifest는 `3d12a19`를
가리켰다. 모델 Build의 성공과 브라우저·배포 Build의 성공은 구분한다.
새 소스는 자체 Cloudflare 모델·브라우저 검증을 통과한 후 배포하며,
공개 호스트 진단은 별도의 후속 증거로 남긴다. 진단은 전체 릴리스
검증을 대체하지 않는다.

시작 상태, 직접 브라우저 관찰과 재현 이미지는
[검증 기록](workbench-verification-2026-11-08/README.md)에 보관한다.
`bitcoincyclescomparison.com`은 원본 참고 사이트이며 이전 대상이 아니다.
