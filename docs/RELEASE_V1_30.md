# v1.30.3 · 봉 리플레이 재생·선택 상태 수정

- 재생은 현재 공개된 실제 봉에서 이어집니다. 확보된 자료 끝에서 Play가 세션 시작점으로 돌아가지 않으며, 처음으로 이동은 별도 버튼으로만 수행합니다.
- 재생 버튼의 이름·도움말·아이콘을 현재 상태와 동기화하고, Select bar 또는 입력 도구에 포커스가 있어도 Shift+↓로 즉시 멈춥니다.
- 시작점 메뉴·날짜/예측 설정·저장된 세션·종료 확인은 하나의 화면 소유 상태로 전환합니다. 일시정지와 메뉴 열림만으로 Play·다음 봉을 막지 않습니다.
- 포인터 캡처 상실·창 포커스 이탈·누락된 mouse-up에서 드래그 상태를 해제하여 가위선이 다시 포인터 아래 주봉을 따라갑니다. 시작 봉 확정 전 Play·다음 봉·최신 차트 이동은 비활성입니다.
- 현재 주황 예측선·갈색 범위·미래 사이클 표시와 일봉으로 누적하는 주봉 OHLC를 보존합니다. 현재 전망을 과거 발행 예측 성적으로 다시 채점하지 않습니다.
- 공모주 화면·수집 자료·워크플로우는 변경하지 않습니다. 검증 및 실제 배포 증거는 PR에 기록합니다.

# v1.30.1 · 공모주 월간 격자와 화면 단위 스크롤

- 상단 월간 달력, 마지막 장 기존 목록. 각 장이 남은 뷰포트 높이를 사용하며 기본 CSS scroll snap으로 이동합니다. 휠을 전역 가로채지 않습니다.
- 날짜 상세 native dialog에 해당일의 모든 청약·수요예측 기간과 주간사를 표시합니다. 혼잡한 날짜의 생략 건수도 표시합니다.
- 월 경계·윤년·중간 달·숨겨진 경로 복귀·키보드·동작 감소·필터 유지 회귀를 추가합니다.
- 낮은 가로 화면에서는 달력 내용을 자르지 않도록 최소 높이와 근접 스냅을 사용합니다. 보통 세로·데스크톱에서는 한 장이 한 뷰포트에 맞습니다.
- 수집 원자료나 모델·전향 기록·루틴은 변경하지 않습니다. 검증 결과는 해당 PR과 CI에 별도로 기록합니다.

# v1.30.0 · 공모주 캘린더

- `?page=ipo`에 수요예측·청약 일정 33건의 수집 스냅샷을 추가합니다. 원자료 수집은 2026-11-01이며 자동 갱신·주문 기능은 없습니다.
- 종목·주간사 검색, 예정/마감/전체 필터, 자료 수집일과 열람일 기준의 상태·D-day를 표시합니다. 진행 중인 일정은 종료일까지 유지합니다.
- 공모금액(백만원)을 억원으로 정확히 환산하고, 희망 공모가 범위와 확정 공모가를 표시합니다.
- 별도 주식·크립토 모델 입력이나 보존된 예측 원장은 바꾸지 않습니다. 공모주 진입은 BTC 데이터·모델 로딩을 기다리지 않습니다.
- 단독 HTML에 동일 일정 스냅샷을 포함합니다. 38커뮤니케이션은 민간 집계이며 변경·오기가 가능하므로 청약 전 DART 증권신고서와 해당 증권사 공지를 확인해야 합니다.
- 사용자 결정에 따라 데이터 포함 공개 PR을 진행합니다. 출처 표기는 재배포 허가의 증명이 아니며, 권리 확인이 완료됐다고 주장하지 않습니다. 리마인더 루틴은 생성하지 않습니다.

검증 결과는 PR과 CI 기록을 참조합니다. 이 문서 자체는 전체 테스트나 배포 성공을 증명하지 않습니다.
