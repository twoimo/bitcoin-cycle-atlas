# WP6 분할 매매 계산·화면 계약

2026-11-09 작성. 이 문서는 이번 구현의 계산 규칙과 직접 재현한 결과를 기록한다. 운영 배포나 브라우저 통과 영수증을 대신하지 않는다.

## 입력과 정보 시점

- 엔진: [`packages/domain/src/rsi-simulation.js`](../packages/domain/src/rsi-simulation.js), 타입: [`rsi-simulation.d.ts`](../packages/domain/src/rsi-simulation.d.ts).
- 입력은 일별 실제 종가와 기존 Wilder RSI14 계산이다. 주봉 표시, 차트 확대 범위, 마우스 선택일은 전략 입력을 바꾸지 않는다.
- `confirmedThrough`는 필수이다. 엔진은 이 날짜와 사용자가 지정한 종료일 중 앞선 날짜에서 가격을 자른 **뒤** RSI를 계산한다. 그 이후 봉은 지표 준비 구간, 신호, 체결, 평가액, 통계 어디에도 쓰지 않는다.
- 화면은 종목/출처의 거래소 시간대로 오늘을 구해 **오늘보다 이른 봉**만 허용한다. 출처의 `lastObservation`보다 뒤인 봉도 제외한다. 미국 거래일과 한국 거래일을 UTC 날짜로 합치지 않는다.
- HUD의 `갱신`은 해당 가격 출처의 `retrievedAt`을 KST로 표시한다. 렌더 시각이나 스냅샷 전체의 생성 시각으로 덮어쓰지 않는다. 별도로 `확정봉` 날짜를 표시한다.
- 현재가는 마지막 사용 가능한 **확정 종가**이다. 실시간 틱 시세라는 뜻이 아니다.

## 상태와 신호

| 현재 보유 | 확정 RSI 조건 | 다음 관측 봉 종가에서 실행 |
| --- | --- | --- |
| 없음 | 직전 RSI > 33.50, 현재 RSI ≤ 33.50 | 첫 트랜치 매수 |
| 첫 트랜치만 | RSI ≤ 29.50 | 두 번째 트랜치 매수 |
| 첫 트랜치만 | RSI ≥ 40 | 첫 트랜치 청산 후 현금 상태 |
| 두 트랜치 | RSI ≥ 40 | 첫 트랜치 청산 |
| 두 번째 트랜치만 | RSI ≥ 43 | 두 번째 트랜치 청산 후 현금 상태 |

첫 진입은 하향 통과로 판정하고, 보유 후 단계는 **활성 기준 충족**으로 판정한다. 한 확정 봉마다 신호 하나만 예약한다. 한 봉에서 여러 기준선을 넘어도 두 주문을 같은 봉에 체결하지 않는다. 첫 체결 뒤 다음 확정 봉에서 활성 기준을 다시 평가하므로, 이미 기준을 넘은 상태를 무시하고 새 교차를 기다리지는 않는다.

두 번째 트랜치가 남아 있으면 첫 트랜치를 재매수하지 않는다. 마지막 신호 뒤에 다음 확정 봉이 없으면 `체결 대기`로 남긴다. 종료일 강제 청산, 손절, 공매도, 차입은 없다.

## 수량과 비용

기본 설정은 첫 매수 50%, 추가 매수 50%, 편도 비용 5bp이다. 비중과 초기 자금, 비용, 계산 기간은 설정에서 바꾸며 종목별로 보존한다.

각 사이클의 첫 매수 직전 현금을 배정 기준으로 삼는다. 첫 트랜치 예산은 이 현금의 설정 비중이며 두 번째 트랜치는 남겨 둔 현금을 사용한다. 각 예산에는 진입 비용이 포함되어 있다.

`수량 = 트랜치 예산 / (체결 종가 × (1 + 편도 비용률))`

`청산 수령액 = 수량 × 청산 종가 × (1 − 편도 비용률)`

`청산 손익 = 청산 수령액 − 트랜치 예산`

평균단가는 남은 트랜치들의 매수비용 포함 원가 합을 실제 수량 합으로 나눈다. HUD 평가손익은 진입 비용과 가정한 청산 비용을 포함한다. 이 가정 평가로 실제 청산 거래를 만들지는 않는다. 최대 낙폭의 일별 평가액은 현금과 보유 수량의 종가 평가액 합이며, 아직 내지 않은 청산 비용은 여기서 선차감하지 않는다.

소수점 수량을 허용한다. 배당, 세금, 환율은 제외한다. 공급자 가격의 과거 판본과 원문 강연의 미기재 매매 조건을 추가로 복원했다는 주장은 하지 않는다.

## 승률과 성과 필드

| 화면 값 | 계산 기준 |
| --- | --- |
| 승률 | 비용 후 청산 손익이 양수인 트랜치 수 ÷ 청산 트랜치 수 |
| n | 실제 다음 봉 체결로 청산된 트랜치 수. 진행 중 보유 및 체결 대기는 제외 |
| PF | 양수 순수익률 합 ÷ 음수 순수익률 절댓값 합. 각 트랜치를 동일 투자금으로 환산 |
| 금액 기준 PF | 실제 복리 운용의 양수 금액 손익 합 ÷ 음수 금액 손익 절댓값 합. 기본 PF와 별도 표시 |
| 거래당 기대값 | 청산 트랜치 순수익률의 산술평균. 실제 금액 손익 평균도 병기 |
| 평균 보유일 | 매수 체결일부터 청산 체결일까지 달력 일수의 산술평균 |
| 최대 낙폭 | 진행 중 보유를 포함한 일별 전체 평가액의 직전 최고점 대비 최대 하락률 |
| 다음 트리거 거리 | 기준 RSI − 현재 확정 RSI. 예: 33.50 − 33.945595 = −0.45p |

청산 표본이 없으면 승률은 `—`, n은 0이다. 손실 트랜치가 하나도 없을 때 PF를 임의의 유한 숫자로 만들지 않고 `손실 없음`을 표시한다.

### 한 확정 봉의 복수 기준 통과: 독립 비교

같은 4,206개 종가와 기존 Wilder RSI14 열을 사용하되, 주문 예약·보유 상태·청산 수익률은 구현 엔진과 분리한 계산기로 다시 계산했다. 모든 경우 편도 5bp, 신호 다음 확정 봉 종가 체결, 진행 중 보유 제외를 유지했다. 아래 네 교차 방식은 두 매수 모두 새 하향 교차, 두 청산 모두 새 상향 교차를 요구한다. 복수 신호를 허용하면 한 확정 봉이 통과한 두 기준의 주문을 순서대로 예약하고 **둘 다 다음 확정 봉 종가**에 체결한다.

| 신호·갭 방식 | 청산 n | 승리 트랜치 | 승률 | 동일 투자금 PF |
| --- | ---: | ---: | ---: | ---: |
| 모두 방향 교차 · 한 봉에 한 신호 | 61 | 43 | 70.4918% | 2.36073 |
| 모두 방향 교차 · 두 매수의 동시 예약만 허용 | 64 | 43 | 67.1875% | 2.28068 |
| 모두 방향 교차 · 두 청산의 동시 예약만 허용 | 64 | 47 | 73.4375% | 3.36360 |
| 모두 방향 교차 · 두 매수와 두 청산의 동시 예약 허용 | 70 | 51 | 72.8571% | 3.61286 |
| 현재 구현 · 첫 진입 교차, 이후 활성 기준, 한 봉에 한 신호 | 66 | 48 | 72.7273% | 3.38445 |

추가 매수와 청산의 교차/활성 기준 여부, 복수 매수·청산 예약 여부를 조합한 16가지 확인에서도 **63건 / 43승(68.3%)은 나오지 않았다.** 복수 매수만 허용한 교차 방식은 두 번째 트랜치 5건을 추가하지만, 잔여 보유로 인해 기존의 첫 트랜치 2건이 진입하지 못하므로 61건에서 64건이 된다. 신호 수만 더해서 차이를 해석할 수 없다.

한 봉에 한 신호라는 제한은 사용자 요청에 명시되지 않은 현재 구현의 추가 가정이다. 이 비교는 그 가정을 원래 전략의 정답으로 확정하거나 참고값의 거래 원장을 역으로 추정한 것이 아니다. 복수 신호 허용만으로 참고값 차이가 해결되지 않았음을 기록하며, 참고값에 맞추기 위한 거래 제외나 규칙 변경은 하지 않았다.
