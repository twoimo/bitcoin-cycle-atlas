# 기준시점 고정 백테스트

2026-11-04, `codex/market-lab-service-20261103`, 로컬 서비스 4319.

봉 리플레이의 BTC 기본 모드를 `기준시점 백테스트`로 바꿨다. 시작 봉이 2026-07-10이면 입력 마감은 2026-07-09 UTC 완료 종가다. 입력과 이후 실제 비교는 모두 Bitstamp BTC/USD 종가를 사용한다. 기존 장기 모형의 계산식을 호출하며 현재 전망의 가격 경로·사후 사이클 주석은 전달하지 않는다. 현재 코드/기본 가정과 당시 날짜까지 발표된 장기 평가 자료를 적용한 재구성이다. 당시 코드·원공표 시각·역사 자료 판본·당시 발행 예측을 입증하는 기능은 아니다.

## 동작

- 시작 봉을 확정할 때 한 번 생성하고, 30/90/180/365/730일 경로와 입력·설정·근거·출력 해시를 고정한다. 검증된 장기 평가 자료의 발표일 때문에 첫 시작 봉은 2025-10-16이다. 빈 날짜/부족한 입력은 오류로 처리한다.
- 일별 실제 봉만 공개한다. 주봉 표시에서도 실제 일별 봉으로 같은 주의 OHLC를 갱신한다. `결과 보기`는 확보한 실제 구간까지 이동하고 입력일/예측 끝이 함께 보이도록 화면을 맞춘다. 실제값이 없는 나머지 날짜는 미확보로 남는다.
- 재생·탐색·차트 유형/표시 기간 변경·저장 복원에서 경로를 다시 계산하지 않는다. 복원은 저장한 경로/입력/설정/근거/레코드의 해시와 시계·자료 정의를 확인한다. 과거 입력이 바뀌면 복원을 거절하며, 미래 실제 자료만 추가되면 기존 경로로 비교한다.
- 새 저장 키는 `atlas-cutoff-backtest-v1:BTCUSD`, 기존 비교 키는 `atlas-chart-replay-v1:BTCUSD`다. 기존 저장본을 덮어쓰지 않는다. 동시 저장에는 기존 revision/lock 보호를 적용한다.
- 기존 `현재 예측선 고정`도 남겼다. 주황 현재선, 파란 별도 회고선으로 구분하며 해당 모드는 기존처럼 채점하지 않는다. 새 백테스트는 파란 고정 예측과 실제 캔들/실선만 비교한다. 네 방향 패널 DOM과 기존 도구 연결을 유지한다.
- MAPE, 종가 유지 기준 대비 로그오차 개선, 기준 종가 대비 방향 일치를 제공한다. 방향 일치는 매일 수익률 적중이나 매매 승률이 아니다. 일별 오차들은 한 경로의 반복 비교이므로 독립 예측 표본 수로 해석하지 않는다. 범위는 보정된 확률 구간이 아니다.

IAB2 작업 탭22에서 7월10일 시작, 입력7월9일, 180일을 확인했다. 입력 5,440개, 고정 경로181점, 10월31일까지 이후 실제114개, 미공개·미확보66일이다. MAPE9.754408558596833%, MAE$7,652.34476172, 종가 유지 대비 로그오차 개선36.856326739568%, 기준 종가 대비 방향102/114였다. 이 한 사례는 모형의 일반적인 예측력을 입증하지 않는다.

실제 출력 해시: `437fc246da22f45ae08a3a08a89737e2e01e6d03cd61f7026c134d1d647dc356`. 일봉 한 개 전진, 결과 보기, 캔들/종가선 전환, 표시 기간 전환, 저장 후 리로드·Continue에서 동일했다. 실제 화면에서 내려받은 JSON을 Python으로 독립 검산했으며, 저장 레코드는 모형 호출 없이 동일 바이트로 복원했다.

기존 현재 전망 출력은 `ee210e3651ddb46c72fdb9c83d826d19b2ab35cf9400a2c4fff156a98ad2faa2`로 이전 감사와 동일했다. 기존 저장 문자열889자의 SHA256 `b303471d661167427396e2994975aee5a041633a9c773d17d695a077ad717b74`는 새 모드 저장 전후 동일했다. 과거 감사 탭15는 이번 마지막 목록에서 없었으므로 그 탭의 최종 화면 상태까지 확인했다고 주장하지 않는다. 다른 탭을 닫거나 복구하지 않았다.

## 검증과 남은 한계

새 모형·UI 검사10개: 미래 가격 변조/제거 불변, 접두부/소스/기간/해시/설정 변조 거절, 빈 날짜/366개 미만 입력/발표 전 날짜/미완료 입력 거절, 저장/복원/오류복구/기간 변경. 새 기능과 기존 ETH·리플레이 회귀 부분집합59개 통과. 초기 전체 검사에서 BTC 모형이 ETH import graph에 들어간 문제를 발견하여 BTC 소유 callback으로만 지연 로드하도록 수정했다. 기존 재생 순서를 보존하면서 추가한 모드·결과 버튼 두 개를 명시적으로 검사하도록 계약 검사를 갱신했다. 별도 결과 로그와 최종 전체 수용은 같은 디렉터리의 verification JSON을 따른다.

기존 모델 관련17개 파일의 해시가 보존됐다. `long-horizon-forecast.js`와 `cycle-calibration.js`도 이전 감사 해시와 비교한다. 컨트롤러16검사와10,000개 유한 명령열/음성 변이 검사가 통과했으며 무한 상태·수학 증명은 아니다. 타입/웹 빌드/정적 참조 검사 통과. Hallmark는 `dist apps/web/src --scope app --genre modern-minimal` 정적57파일 검사에서 신규 replay 지적0; 전체 기존FAIL9/REFLEX2/WARN10을 기록했다. 옵션이 다른 과거 보고서의 REFLEX 수와 개선율 비교를 하지 않는다. upstream 브라우저 렌더는 실행하지 않았으며 IAB 실제 검증을 별도로 기록했다.
