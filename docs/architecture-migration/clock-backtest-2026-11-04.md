# 거시 시계 보정 효과 검증

2026-11-04 KST. `백테스트 → 거시 시계`에서 기존 48개월 무보정 시계와 현재 보정 규칙의 고점·저점 날짜 오차를 비교한다. 기존 월말 가격 검증과 같은 중앙 영역을 사용하고 상하좌우 도구를 유지한다. 로컬 구현·검증 기록이며 배포나 모형 승격이 아니다.

## 계산 범위와 표본

기존 `cycle-calibration.js`의 고정 분기 원점 16개(2018–2019·2022–2023년)와 종료 반감기 구간 목표 선정 규칙을 그대로 호출한다. 각 원점까지의 관측만으로 기준 고점·무보정 날짜·보정 일수를 재구성한다. 고점은 기준 고점 +48 달력 개월, 저점은 무보정 고점 +12 달력 개월이다. 두 날짜에 같은 정수 일수 보정을 더한다. 윤년에는 보정된 고점에 다시 12개월을 더하는 것과 다를 수 있으며 기존 계산 순서를 유지했다.

목표는 다음 관측 반감기로 해당 구간이 종료된 뒤에만 채점한다. 실제 고점·저점은 평가에만 사용하며 원점의 예측 입력으로 전달하지 않는다. 같은 반감기 구간과 전환 종류를 하나의 목표로 묶고, 같은 목표·원점의 중복 행은 제거하며 충돌은 거절한다. 목표 안에서 원점별 절대 오차를 먼저 평균하고 목표마다 동일 가중한다. 목표 수·서로 다른 원점 수·고유 사이클 수를 별도로 표시한다. 고점과 저점이 같은 사이클에 속하면 사이클은 하나다.

실제 IAB 내보내기 입력은 Coin Metrics 계열 5,952개 일말 관측, 마지막 날짜 2026-11-02다. 저장된 기본 자료 파일의 2026-10-31과 구분한다. 브라우저 평가 입력 SHA256은 `dee17c6bcbc65582815d4c00290bba79755b03c7b92b8bf39c7141db6187b636`이다. 원점 8개가 2020 반감기 구간의 고점 2021-11-08·저점 2022-11-09를 공유하며 목표 고정일은 2024-04-20이다. 2022–2023년 원점 8개는 다음 구간 미종료로 보류한다.

| 목표 | 고유 목표 | 원점 | 무보정 MAE | 보정 MAE | 오차 감소 |
|---|---:|---:|---:|---:|---:|
| 고점 | 1 | 8 | 38일 | 21일 | 17일 |
| 저점 | 1 | 8 | 37일 | 20.5일 | 16.5일 |

고유 사이클은 전체 하나다. 8개 원점을 8개의 독립된 목표나 사이클로 세지 않는다. 현재 규칙을 현재 보존 자료 판본에 적용한 회고 비교로, 당시 발행 예측·당시 빈티지·일반적인 예측 우월성을 입증하지 않는다. 새 표본 선택이나 보정 매개변수 최적화는 하지 않았다. 가격 경로의 극값, 시나리오의 도달·체류 개월, 표시 기간의 적용 제한은 이 달력 시계 규칙 평가와 구분한다.

현재 조건부 시계는 별도 펼침 영역에 채점 제외로 표시한다. 2026-11-02 관측, 기준 고점 2025-10-06, 보정 −56일: 고점 2029-10-06 → 2029-08-11, 저점 2030-10-06 → 2030-08-11. 아직 결과가 관측되지 않아 과거 성적에 포함하지 않는다.

## 구현과 보존

순수 평가 모듈·전용 worker·중앙 뷰를 추가했다. 기존 계산 모듈은 수정하지 않았다. 월말 뷰에는 선택적 종류 전환과 공유 진입점 소유권만 추가했다. 기존 `백테스트` 버튼 ID, 월말 고정본/리플레이 저장 키, 30·90·180·365일 경로 계산을 유지했다. 새 스타일시트 대신 기존 월말 스타일 안에 범위를 한정했다.

결과를 받으면 입력 해시·기준일·목표 그룹·날짜 산술·집계를 검증한다. 새 실행은 이전 성적과 내보내기를 비운다. 닫기·종류 전환·다른 페이지·봉 리플레이 진입은 소유 요청을 취소하며 늦은 결과를 수락하지 않는다. 로딩·오류·빈 종료 목표·보류·정상 상태를 구분한다. JSON에는 입력 관측과 원점별 날짜·오차·집계·자료 메타데이터를 포함한다.
