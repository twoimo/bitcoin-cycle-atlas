# 거시 시계와 예시 경로의 기간 비교

2026-11-04 · `codex/market-lab-service-20261103` · 로컬 서비스4319 · 관측 입력2026-11-02 UTC.

거시 사이클 달력 시계와 예시 가격 경로의 전환점을 분리했다. 거시 시계는 가격축에 참여하지 않는 ◇ 날짜선으로 표시하며, 미래 경로의 기존 극값 표식에는 `경로` 접두어를 붙인다. 원래 marker ID·날짜·가격·선정 규칙·기간선 끝점은 그대로다. 현재 고점 시계2029-08-11/저점 시계2030-08-11과 경로 고점2029-07-19/저점2029-10-02가 서로 다른 의미임을 차트·범례·선택 상세에 표시한다.

## 표시와 계산 범위

미래 기간선의 공간이 충분하면 과거 최솟값–최댓값·표본 수와 설정 민감도·성립 개수를 함께 표시한다. 짧은 기간선은 기존 축약 라벨을 유지하고 전체 tooltip/ARIA·선택 상세·기간선 메뉴에서 확인한다. 기간선 메뉴에는 9개 관계의 선택 경로, 과거 분포(최소/Q1/중앙/Q3/최대), 7개 설정 범위를 표시한다. 원자료별 시작·종료 UTC 날짜와 일수는 기존 상세 패널의 페이지 넘김에서 볼 수 있다. 설명은 기존 방식대로 접힌 기준 항목에 둔다.

과거 표본은 완료 관측 구간이며 잠정·가정·부분 구간·일수 불일치·중복 사이클을 제외한다. MID-TOP은 과거 반감기 창과 미래 상승 창 첫⅓의 정의가 달라 과거 분포를 제외한다. 나머지 관계도 과거 사후 선정과 미래 시계 창의 차이를 명시한다. 역사 분포는 미래 기간 예측의 검증 성적이 아니다.

민감도는 기존 경제 가정5개(통화·금 기준/채택 확대/완만한 채택/낮은 채택/수요 훼손)와 선택 가정의 보조 시드2개를 같은 기존 모형에 넣은 7개 설정의 최솟값–최댓값이다. 시드는20261022/23/24를 사용한다. 기준점이 성립하지 않는 설정을 0일로 채우지 않고 실제 성립 개수와 미성립 개수를 표시한다. 확률분포·신뢰구간·성적이 아니다. 거시 시계의 작은 날짜 범위도 무보정·현재 보정·원시 보정의 시계 민감도다.

현재 BOTTOM→BOTTOM은1190일/170주다. 과거1153–1431일(164.7–204.4주), 중앙1425일(203.6주), Q1=1289/Q3=1428, n=3이다. 설정 범위667–1279일(95.3–182.7주),7/7개다. CYCLE TOP→BOTTOM의 현재75일과 설정7–584일도 축소하거나 감추지 않는다. FIRST TOP은3/7개, ATH는6/7개가 성립한다.

## 소유권과 보존

BTC 소유의 별도 비교 worker를 기존 forecast-computation 계약으로 실행한다. 관측 자료·선택 모델 revision을 묶고 취소·빠른 가정 전환·늦은 완료에서 옛 결과가 현재 표에 들어가지 않도록 한다. 계산 중/오류/자료 없음/기준점 미성립을 구분하고 실패는 명시적 재시도로 복구한다. 원래 가격 모형 캐시와 보조 민감도 캐시는 분리했다. 같은 모델의 캐시된 비교 결과로 돌아와도 취소된 작업을 정상 재개한다.

`cycle-milestones.js`, `long-horizon-forecast.js`, `detailed-forecast.js`, `cycle-calibration.js`, `cycle-decision.js`, `chart-replay.css`는 작업 전 SHA256과 모두 동일하다. 실제 renderer의 원래 가격 path·가격축·시간축·수치 좌표가 새 주석 전후 동일함을 검사했다. 네 방향 패널을 교체하지 않았으며 새 주석은 기존 BTC 현재 차트와 기간선 설정에만 연결했다. 저장된 고정 백테스트에는 새 현재 민감도를 주입하지 않는다.
