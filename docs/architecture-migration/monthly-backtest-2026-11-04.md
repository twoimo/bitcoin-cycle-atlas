# 월말별 고정 경로 자동 백테스트

2026-11-04 KST · `codex/market-lab-service-20261103` · 로컬 서비스4319.

상단 `월말 검증`을 열면 중앙 가격 영역에 월말별 성적 표를 표시한다. 기존 상하좌우 패널과 실제 BTC 차트 DOM을 유지한다. 완료 UTC 월말을 자동 나열하고, 그 날짜까지의 Bitstamp BTC/USD 종가와 발표일이 확인된 기존 장기 평가 자료만으로 기존 cutoff 모형의365일 경로를 한 번 고정한다. 동일 경로의30·90·180·365일 구간을 비교한다. 원래 계산식·기본128개 표본·시드20261022·블록28일·선택 경제 가정을 유지한다.

## 자료와 성적의 의미

확인된 장기 평가 자료의 발표 시점과366개 이상의 연속 완료 종가 조건 때문에 첫 검증 월말은2025-10-31이다. 현재 실제 Bitstamp 종가는2026-10-31까지이며13개 월말을 포함한다. 현재 코드와 보존 가격 판본을 이용한 과거 재구성이다. 당시 발행 예측·당시 소스 코드·역사 자료 판본이 입증된 성적으로 취급하지 않는다. 월말마다 새 자료를 몰래 사용하거나 현재 Coin Metrics 전망을 입력하지 않는다.

매월 말의365일 경로 전체를 고정한 뒤 네 기간을 같은 경로에서 자른다. MAPE/MAE는 기준일 다음 날부터 목표일까지의 일별 종가 오차, 종료일 오차는 정확한 목표 날짜 한 점의 절대 백분율 오차다. 종가 유지 대비는 `1 − 평균 절대 로그오차 / 종가 유지의 평균 절대 로그오차`이며 양수일 때 오차가 작다. 종료 방향은 기준일 종가 대비 상승·하락·보합 일치 횟수다. 일일 수익률 적중이나 매매 승률이 아니다.

요약은 성숙하고 모든 일별 실제값이 있는 구간만 포함하며 기준일마다 같은 가중치를 준다. `네 기간 공통 기준일`을 켜면 모든 기간에 같은 완료 원점만 사용한다. 현재 공통 원점은2025-10-31 하나다. 평가 기간이 겹치므로12·10·7개 기준일이 독립된 사이클 표본 수를 뜻하지 않는다. 미래는미성숙, 완료일이 지났지만자료가 없으면자료대기, 중간날짜가빠지면관측누락이며 부분 성적을 완료 요약에 넣지 않는다. 월말 입력이 빠진 날짜도 목록에서 숨기지 않고 고정 실패로 남긴다.

## 고정본 보존과 리플레이

별도 IndexedDB `atlas-monthly-backtests`의 `forecasts` 저장소를 사용한다. 요청 키는 월말 입력 접두부·완료365일·발표 시점으로 제한한 설정·자료 의미·현재 수집한 계산 소스 식별자를 결합한 SHA256이다. 각 기록은 본문/입력/설정/출력 해시를 검증한다. 같은 키는 readwrite 트랜잭션의 첫 수락본만 남기며 동시 계산도 그 수락본을 다시 읽어 사용한다. 실제 가격의 미래 접미부만 추가돼도 기존 경로와 생성 시각을 그대로 복원한다. 과거 입력이나 계산 소스·설정이 달라지면 별도 키로 보존하며 이전 기록을 덮어쓰지 않는다. 손상된 저장본은 자동으로 새 예측을 만들어 대체하지 않는다.

중단은 현재 소유 요청과worker를취소하며 이미수락된월말은남긴다. 늦은 자료·worker 결과는 현재표/내보내기를 바꾸지 못한다. 저장응답을잃으면배치를중단하고다음확인에서같은키를조회해수락여부부터확인한다. 저장소 사용 불가를 성공으로 대체하지 않는다. 실제 검증은 로컬 HTTP 서비스에서 지원하며 오프라인 단일 HTML은 명시적으로 서비스 진입을 안내한다. 기존 오프라인 차트/리플레이 모듈과 스타일은 그대로 패키징한다.

표의기간셀을누르면기존봉리플레이로연결한다. 짧은기간도보존365일경로의정확한접두부를사용하고새모형을계산하지않는다. 고정본의시작일·모드·기간편집은잠그고재생·탐색·실제공개·표시유형·계산상세·JSON을유지한다. 월말리플레이의종료는기존수동저장키두개에쓰지않는다. 평소봉리플레이는이전과같이이어가기/새시작/저장한다.

이 기능은 열 때 완료된 월말을 자동 계산·복원하는 배치다. 앱이 닫힌 동안 실행되는 새 수집기나 백그라운드 스케줄을 설치하지 않았다.
