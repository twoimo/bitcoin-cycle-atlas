# v1.26 · 공항 안내판 스타일의 다크 자산 비교표

## 화면
- 기존 다크 테마의 표면·글자·상승/하락 색을 유지하고 노란 안내 색상과 정렬된 숫자를 적용했습니다.
- 복귀, 제목, 갱신, 읽는 법, CSV가 데스크톱과 모바일에서 한 줄로 표시됩니다.
- 모바일의 중복 복귀 버튼과 빈 여백을 제거했습니다. 표는 내부에서만 가로로 이동하며 종목명은 고정됩니다.
- 판단 설명창과 오류·빈 상태도 다크 테마입니다.

## BTC와 계산
- BTC가 첫 행인 총 18개 자산입니다. 기존 BTC 일별 원자료 5,942개(2010-07-18~2026-10-23)와 실제 출처 URL·해시를 재사용합니다.
- BTC UTC 달력일과 주식·ETF 거래일을 구분하며, 누락·윤일·부분 연도와 올해 기준일을 검증합니다.
- 기존 17개 자산의 원자료와 전체 계산 결과는 이전 main과 동일합니다.
- 과거 연도 동일 가중 평균과 다섯 단계 위치 분류를 유지합니다. 평균 낙폭은 MDD가 아니며, 미래 가격·수익성을 검증했다는 뜻이 아닙니다.

## 검증

- 공개 Pages에서도 BTC 18개, 다크 표·설명창, 한 줄 헤더, 마지막 행 접근, 표 내부 가로 이동, 복귀 및 실제 CSV 다운로드(18행·34필드)를 확인했습니다.
- PR #28의 CI는 기존 형식 검증을 포함해 통과했고 Pages run 40217269209가 성공했습니다.

- 현재 버전의 릴리스 문서 존재 여부를 확인하는 회귀 테스트를 추가합니다. 웹 계산·표 데이터·연구 모델은 변경하지 않습니다.
- 기존 ETH 예약 갱신 문제와 PR #12는 별도 범위로 보존합니다.

## v1.26.2 사용성 고도화

- 모바일 표본·평균 / 가격·판단 빠른 이동, 핵심 열 맞춤 및 세부 분류의 설명창 제공.
- 선택 종목의 올해 등락률·과거 평균 상승·낙폭 요약과 일반 계산법 접기.

- [실제 브라우저 검증 범위](AIRPORT_BOARD_V1_26_2_QA.md).

## v1.26.3 안내줄 제거
- 표 위의 자산 수·비교 연도·최근 관측·출처 안내줄을 제거했습니다.
- 불러오기·오류·재시도 안내는 보존하며 성공 후에는 안내줄의 공간도 남기지 않습니다.
- 기존 18개 자산, 계산과 CSV는 그대로이며 출처와 기준일은 설명창·CSV에서 확인할 수 있습니다.

## v1.26.4 하단 안내 영역 제거
- 표 하단의 자산 수·가격 기준·상승/하락 범례와 주의 문구 영역을 제거했습니다.
- 계산법·MDD 구분·배당 제외·미래 예측이 아니라는 주의사항은 기존 ‘읽는 법’에 유지합니다.
- 표의 접근성 설명에 삭제한 영역을 가리키는 참조가 남지 않도록 정리했습니다.
- 기존 18개 자산과 계산·CSV·오류/재시도 안내는 그대로입니다.

## v1.26.5 수치·성능·입력·갱신 감사

- 시장 국면의 이동 계산을 분할상환 O(N)으로 개선하고, 가격 단위에 따라 동률 국면이 달라지는 수치 오차를 수정했습니다. 과거 기준일까지의 계산은 이후 가격 값의 오류에 영향을 받지 않으며 전체 날짜 형식·순서·누락 검사는 유지합니다.
- 자산 비교표의 정확한 평균 경계에서 발생하던 부동소수점 판정 차이를 보정했습니다. 현재 저장된 18개 자산의 판단 단계와 기존 다크 화면을 유지합니다. 상세 전망 API의 기본 발행일은 최신 완료 관측 뒤로 이동합니다.
- 명시적인 새로고침은 이전 과거 캔들 실패의 대기를 해제합니다. 일반 조회의 대기와 요청 소유권 방어는 유지하며 BTC·ETH 실제 함수로 회귀를 검증합니다.
- 터치 추적의 중복 표시를 프레임당 최신 한 번으로 합치고, 분석 창·상세 패널 조절은 최초 포인터의 마지막 좌표를 반영합니다. 취소·숨김·capture 상실 뒤 늦은 입력은 반영하지 않습니다.
- 선택적 외부 글꼴 실패가 사이트 시작을 막지 않도록 필수 CSS와 분리했습니다. 독립 실행 HTML은 외부 글꼴 요청 없이 동작합니다.
- 날짜가 늘어난 정상 자료를 잘못 거부하던 정기 갱신 테스트를 고정된 과거 관측 검증과 미래 날짜 생성으로 수정했습니다. 가격·자료 검증 조건은 완화하지 않습니다.
- 실제 upstream pstack으로 재시도 상태 모델과 한국어 전후 상태전이도를 만들고, 기존 BTC·ETH·주식 상태 모델 및 실제 코드 변이를 다시 검사했습니다.
- 범위·실행 결과와 한계: [2026-10-26 심층 감사](DEEP_AUDIT_2026-10-26.md).
